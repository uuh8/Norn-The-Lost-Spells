## 1. 当前已经确定的方向

本轮目标是让现有法术编程与“万物皆元素”的材料世界形成可持续游玩的核心循环，同时通过有限地图、物资进出和世界生命周期控制材料累积。单机核心需求已完成讨论并整合到总案；实施前仍需审阅其中明确标记的技术提案。PvP 暂缓，剧情在后期地图与核心循环成熟后再加入。

以下内容来自用户本轮明确提出的方向：

| 项目 | 已确定方向 |
|---|---|
| 世界规模 | 采用箱庭地图，例如豪宅、有限森林、小村落。 |
| 玩家入口 | 玩家进入游戏后位于类似新手村的据点箱庭。 |
| 据点功能 | 首版提供仓库整备、商店、消耗真实库存的材料实验及法术试验；设备与新增炼金规则延期。 |
| 模式范围 | 优先完成单机箱庭；PvP 暂停讨论与开发，保留为未来方向。 |
| 单机地图内容 | 首版只做一张地图，由用户寻找网上场景作为基础，再添加已有元素、敌人、机关和收获。原场景墙体、地面与家具不在首版全面改造成可采材料；被动与据点设备延期。 |
| 撤离与 Boss | 有轻量条件的基础撤离路线，支持短途取料；深区与 Boss 提供更好收益或捷径，具体布置由场景确定。 |
| 撤离交互 | 主动启动短倒计时，区域内可移动与施法，普通受伤不打断；离开或主动取消后重新计时，死亡按失败结算。具体秒数与范围待定。 |
| 冒险生命周期 | 箱庭不保存续玩；成功撤离才能带出物资。死亡、强退及主动关闭游戏按失败处理，带入和新收获的普通资产损失，尚存受保护法术保留；据点仓库保持。异常崩溃的具体恢复策略仍留作实施边界。 |
| 单机地图规则包 | 普通地图不设强制撤离总倒计时；固定箱庭布局内进行有限变化，提供不同风险与隐藏路线；单局原有资源、敌人和增援有边界；Boss 与探索各有独特收益。具体地图与数值待设计。 |
| 可获取资源 | 包括稀有法术、稀有液体、敌人掉落物等。 |
| 背包意义 | 玩家合理安排背包，把物资带出地图。 |
| 背包形式 | 采用二维格子，按尺寸、形状、朝向拼放，允许丢弃。具体尺寸与上限为配置数值；堆叠资格见下文。 |
| 跨局积累 | 带出的物资可以在下一次单机箱庭冒险中携带、使用。 |
| 物品保护 | 初始 2 个保护名额，每份法术占一个，不限稀有度；出发前选择并在本次冒险中锁定对象。本局新搜获必须成功撤离才能保留。费用、成长扩展与结算规则待定。 |
| 冒险物资 | 普通消耗品、空容器与状态相同的法术可有限堆叠；次数、附着或材料组分不同的物品分别保存，法杖保持独立。各类上限由数据配置。 |
| 法术次数与死亡 | 法术可无限使用或具有有限次数；在箱庭中死亡时，无限使用法术也会丢失。结合已认可的保护方向，受到保护的例外与具体结算继续细化。 |
| 有限法术结算 | 成功撤离或受保护后死亡时保留真实剩余次数，已用次数不恢复；次数耗尽后法术消失，保护也不恢复。本次冒险的保护名额不能转移给其他法术。 |
| 修正与多重施法次数 | 已装入三根法杖的卡入场扣一次携带次数；背包备用卡本局首次安装时补扣，卸下重装不重复扣。本局无限使用；最后一次资格本局仍有效，终局后该卡耗尽。 |
| 普通产出法术次数 | 按指令执行扣一次，不随同一次执行的分裂数量增加扣次；无限使用法术不扣使用次数，仍受法杖 Mana 与冷却约束。 |
| Trigger 次数 | 成功施法开始时预扣 Trigger 与后续 Payload 的有限次数，未触发不退；Mana 不足导致整次失败不扣。修正与多重施法按携带资格处理，不再按施法扣次。 |
| 装备死亡损失 | 携带的法杖本体、容器及其中材料、背包本体与其他携带物死亡时遗失；仍存在的受保护法术按保护规则带回。据点未带出的仓库资产及已取得的永久资产保留。 |
| 重新出发保障 | 免费基础套装只补缺项，不能出售或通过拆解直接变现；连续失败后仍可补领，不设每日次数或等待时间。具体套装规格与资格判断细节待定。 |
| 出发存放位置 | 玩家最多携带 3 根法杖，数字键切换。各自具有 Mana 上限/恢复、冷却、槽位容量与每次抽取数量，未握持也按自身规则恢复；切换不重置资源或冷却。法术排列为 WandLayout，资产归属独立。 |
| 容器收集 | 靠近材料，以固定速度采集；混合材料采样后仍保存混合组分。顺利撤离后带回据点。 |
| 容器释放 | 首版包含投掷破碎、慢慢向前撒出、附着某份法术三种用途；投掷破碎后容器本体损失，实际存料转入场景。 |
| 材料附着 | 玩家可选择将容器材料附着在法术上；法术具有自身元素，容器材料为空时仍可正常释放法术。 |
| 附着对象与持续方式 | 为法杖中的某份法术独立配置附着，持续保留配置，实际执行产生输出时取料；关闭或调整后改变配置，材料耗尽时仍可普通施法。具体剂量、来源关联与组合输出计量待细化。 |
| 附着不足 | 不足一次剂量时部分附着，不取消基础施法。多输出间的材料分配与剂量操作待细化。 |
| 容器扩展玩法 | 用户认可采集兼具环境处理、少量投放试探、投掷易碎容器和临时涂覆四个方向；具体规则、效果与参数尚未确定。 |
| 实际采集 | 玩家从场景收集多少材料，场景中的对应材料就减少多少。 |
| 容量分工 | 法杖中的法术使用法杖独立容量；容器占用背包容量，扩充容器容量会挤占其他物资空间。 |
| 容器分装 | 普通容器允许多种材料同腔存放；独立瓶子或分仓容器用于保存独立样本。同腔不默认立即均匀融合，具体反应后续设计。 |
| 材料携带 | 可搬运的稳定固体可直接作为材料物品放入背包，也可装入合适容器；液体和气体通过容器保存。特殊固体的保存要求及采集工具后续设计。 |
| 永久成长 | 已取得知识及据点资产保留；被动技能首版暂不做，用户允许后续头脑风暴。具体炼金发现机制待设计。 |
| 永久据点资产 | 据点库存跨局保存；设备与其解锁、供料及升级玩法首版暂不做，留待炼金扩展。 |
| 商店与实验 | 首版买卖法术、法杖、元素与容器；设备暂不供货。有限货源与收购预算随明确的冒险进展更新，反复进出不刷新；材料身份不按法术来源区分。实验消耗真实库存，具体价格、预算与进展事件随后配置。 |
| 敌人掉落 | 首版敌人死亡概率掉落各种法术；不加入设备部件、图纸、货币实物或其他杂物掉落。扩张后再设计更多掉落类型。 |
| 炼金后续内容 | 用户后期提供长篇炼金规则表，记录不同物质融合产生的物质；当前预留扩展需求，暂不讨论具体反应表或实施开发。 |
| 当前优先级 | 先完成单机箱庭的核心玩法与开发，PvP 暂缓，剧情后期补充。 |

此前已经确定的“万物皆元素”原则继续保留：固体、液体、气体属于同一个材料世界，法术、环境、角色与敌人都能成为材料规则的生产者或消费者。材料不仅用于表现法术，还应成为探索、战斗、采集与炼金的对象。

首版为单机；PvP、被动、设备和具体炼金表延期。撤离时间与范围、基础补给规格、保护费用、容量与价格等配置值，以及崩溃异常处理仍需在实施设计中明确，不能把未确定数值写成已确认玩法。

## 2. 玩法定位与核心循环

当前总体定位：**据点驱动的单机箱庭法术搜集撤离游戏（Hub-based Extraction）。** PvP 保留为未来方向，用户已明确要求暂不讨论、优先完成单机部分。具体建议与规则仍逐项确认，不将总体认可解释为所有备选机制已经确定。

玩家带出物资后能够在后续冒险中使用，形成跨局资产积累。这使核心更接近 Extraction。Roguelite 的随机奖励、事件与组合变化仍可借鉴，但是否加入这些变化、变化到什么程度，需要服务于本项目的探索和材料玩法。

建议的循环为：

```text
据点整理仓库、配置法术与携带物
→ 选择箱庭地图并进入一次冒险
→ 探索、战斗、采集材料、发现法术与隐藏物
→ 根据背包、补给和风险决定继续深入或撤离
→ 成功撤离后结算，把带出的物资存入仓库
→ 试验新组合、炼金或补给，准备下一次冒险
```

仓库、出发配置、真实采集、撤离结算与跨局积累已经逐轮确认；首版完整范围以 6.9 为准。具体数值与地图布局由实施设计和试玩收敛。

“继续深入”需要有玩家能够判断的收益和风险：例如接近稀有材料产地、打开隐藏房间、挑战 Boss，同时消耗补给、占用背包并提高撤离难度。本局新搜获物资只有成功带出后才能进入长期资产，这一点已确认；永久知识与能力在何时取得仍需单独设计。

首版采用有轻量条件的基础撤离路线，兼顾少量取料；深区与 Boss 可提供更好的收益或捷径。原“出口开局无条件可用”和“必须击败 Boss 才能撤离”均不作为首版通用规则。

### 2.1 最新方向：地图专属撤离条件与 Boss 的定位

用户最新说明：普通冒险时长不固定，玩家可能只为据点实验缺少的少量材料出发；同时不希望箱庭能够马上出去。地图可通过机关、打开房门、击杀最终 Boss 或特殊小怪等具有背景与环境联系的条件开放撤离。

撤离通过地图中的实际出口完成，具体提示、条件和出口数量待设计。此前“至少一个常规出口从开局可用”被最新方向覆盖；出口解锁后是否继续沿用已讨论的短倒计时与区域交互，需在具体流程中核对。

用户已认可基础出口需要较轻的地图任务，深区或 Boss 可开放捷径与额外收益。具体机关、守卫与出口位置等拿到首张场景后设计，不能把示例自动写成场景既有内容。

首版保留基础撤离路线，Boss 不作为全部冒险的必需门槛；未来其他地图的专属撤离条件另行设计。

### 2.2 已确认方向：出口交互与撤离等待

用户已认可到达撤离区域后主动交互一次，启动一段短暂的撤离准备倒计时。倒计时期间玩家可以在区域内移动、施法和防御；留在区域内存活至准备完成后撤离。风险主要来自返程路线和现场已有的敌人、元素危险，特定出口事件可后续另行设计。

普通受伤不打断准备，离开区域或主动取消则结束本次准备，重新启动时从头计时；死亡按失败结算。这些规则已确认，能避免毒雾或燃烧的连续伤害使玩家反复无法完成撤离，同时保留在危险区域中坚持至结束的风险。具体撤离范围、边缘提示及取消操作后续设计。

| 候选交互 | 体验 | 主要取舍 |
|---|---|---|
| 主动启动、区域内短暂等待（已选择） | 可以边防御边等待，玩家清楚知道何时完成 | 需要清晰显示区域和剩余时间，时间过长会拖慢短途探索。 |
| 抵达后立即撤离 | 返程到出口就能结束 | 操作简单，紧张感主要由路程提供。 |
| 站定持续交互、受伤打断 | 完成前需要创造安全窗口 | 有额外清场与防守要求，持续状态伤害下可能反复无法完成。 |

建议先以 5 秒作为短等待的讨论起点，具体数值尚未确认，也未通过试玩平衡；等待时间和范围需要结合敌人速度、攻击节奏与出口地形调整。撤离完成时按实际携带物结算，正在地面或空中的未收集材料继续属于场景，不自动进入玩家库存。

普通撤离的倒计时、区域行动与中断方式已确认，具体秒数与范围后续再定。

### 2.3 最新方向：箱庭不保存，结束后重置

用户最新决定箱庭不提供保存功能，强行撤退失去本次物资。此前“中途保存退出、恢复同次冒险”已取消。一次出发到撤离、死亡或放弃仍是独立实例；新一轮按地图初始规则建立敌人、资源、机关及材料。据点仓库与跨局资产保存仍有必要，不能把取消箱庭续玩理解为取消全部存档。

| 情况 | 世界处理 | 资产处理与确认状态 |
|---|---|---|
| 同一冒险内离开局部区域再返回 | 远处区域按已有方向暂停，返回后恢复本次状态 | 保持本次携带物和已发生的消耗，不重新生成被采集物资。 |
| 箱庭主动关闭游戏，不提供续玩 | 不保存该冒险世界 | 按失败处理，普通带入与新获取资产损失，尚存受保护法术保留；崩溃恢复策略另行明确。 |
| 成功撤离 | 结束实例并释放其世界状态 | 按实际携带物结算进入据点。 |
| 死亡 | 结束实例并释放其世界状态 | 按已确认损失规则结算，带回仍存在的受保护法术。 |
| 强行撤退或主动放弃 | 结束实例并释放其世界状态 | 按死亡规则，带入与新获取的普通资产损失，尚存受保护法术保留，据点库存不受影响。 |

取消冒险磁盘续玩可以减少材料世界序列化与恢复的实现范围；同次冒险中圈外区域冻结、返回恢复仍属于运行时状态管理，与保存退出不同。实例结束释放不单独解决同一场长时间战斗的材料累积。

据点持久化、出发资产归属与终局结算仍需避免重复或丢失；正常退出与保护规则已确认，异常崩溃的具体处理在实施设计中明确。当前没有开发这些功能。

### 2.4 已确认规则包：单机地图节奏、探索收益与永久成长

用户要求每轮集中讨论更多内容再确认，且已整体认可本节 7 点作为单机箱庭的初始方向。具体数值留待试玩与后续规划；示例不自动成为地图实施任务。本组不设计具体炼金配方，不启动开发。

| 编号 | 已认可方向 | 设计目的与取舍 |
|---|---|---|
| 1. 冒险时间 | 普通单机地图先不设强制撤离总倒计时，玩家依靠背包空间、补给、有限探索收益与路线风险决定返程；特殊限时地图或事件以后单独设计 | 给实验、观察与探索留出时间；长时间游玩的性能仍需材料世界自身管理。 |
| 2. 每局变化 | 固定箱庭布局，在预设候选位置内变化部分战利品、材料种类、敌人编组和事件；地图专属撤离条件的关键对象与通路保持可完成 | 熟悉地图仍有价值，也保留重复游玩的新鲜感；变化不能制造无法满足撤离条件的局面。 |
| 3. 路线与风险 | 提供相对容易进入的基础区域、危险且奖励更丰富的区域、带探索或解法要求的隐藏区域；危险来源可以是敌人、材料环境或地形，不必只靠敌人数值 | 支持短途采集和深入探索；重要普通路线建议具有多种可行解法，特殊法术可以提供便利，个别专属秘密的要求应清楚可知。 |
| 4. 单局资源 | 初始宝箱、材料储备与普通敌人消耗后保持本次状态，离开区域不刷新；增援有有限数量，持续材料来源由实际储备等世界规则约束 | 单次冒险收益有边界，减少反复刷新带来的奖励和物质累积；玩家、敌人的法术生成量与开销仍需另外设计。 |
| 5. Boss 与探索奖励 | Boss 提供主题明确的稀有法术、特殊材料或装备候选；隐藏探索、危险采集和事件也能带回有吸引力的收获。稀有法术更难获取、效果更强 | 各类出发目标都值得投入；是否必须击败 Boss 由地图撤离方案进一步确定，具体强度与掉落率待定。 |
| 6. 永久成长获取 | 亲自观察并验证的材料规律可以立即记录为知识；被动能力、据点工具等需要带回的实体解锁物成功撤离后再用于永久解锁 | 玩家已理解的规律不会因死亡失忆，实体奖励仍受撤离风险约束；具体哪些能力即时取得或通过实体解锁须逐类设计，未知配方发现与验证机制留待未来炼金专题。 |
| 7. 保存与放弃（已修订） | 箱庭不保存，强退/主动关闭按死亡损失，普通带入与搜获资产遗失，尚存受保护法术保留 | 无需保存整个冒险世界；据点持久化及异常退出策略仍需实施设计。 |

以豪宅地图为候选例子：外院可采集普通材料和补给，地下区域有危险材料与更好的战利品，书房或阁楼提供隐藏探索，Boss 提供与豪宅主题有关的专属奖励。每次具体收获可以变化，建筑结构与主要路线保持可学习。这只是示例，不确定首张地图、具体剧情或任何元素反应配方。

性能方面，上述有限来源与实例结束释放可以控制一部分材料输入及跨局累积；大量施法仍能在同一场战斗内累积物质，需要结合既有远处暂停恢复、静止材料的低成本表示、采集、排水、通风和消耗规则管理。暂不以统一限时或直接删除仍可见物质作为普通地图的默认规则，也不宣称该玩法包已经保证目标帧率。

本组 7 点已经整体认可。原拟讨论的 PvP 专题按用户最新要求延期，接下来补齐单机部分尚未确认的需求与关键规则。

## 3. 元素世界如何形成特色玩法

### 3.1 地图资源与环境可以共同参与玩法

建议把物资获取融入材料环境：玩家除了打开容器，也能发现液体池、固体矿脉或气体聚集区。用户已确定靠近并以固定速度采集，混合采样保留组分；可采对象、是否涉及原场景地面墙体、工具、范围与危险程度仍待设计。

以下为玩法示例，均未确定为正式规则，也不代表当前已实现：

- 豪宅的地下炼金室存在稀有液体，但入口被危险气体覆盖，玩家需要处理环境后进入。
- 森林中的稀有材料会被当地怪物守护，玩家可以选择战斗、绕行或利用环境。
- 村落的隐藏房间需要借助固体、液体或材料反应打开另一条路径。

每张地图的差异可以来自地形、材料分布、敌人、采集条件和隐藏路线。首版只做一张用户寻找的场景，随机刷新细则与可破坏程度尚待确定。

### 3.2 背包需要形成“带什么、留什么”的选择

用户已经确定合理安排携带空间是核心之一，并明确法杖容量与背包容量独立，已装入法杖的法术使用法杖槽位。容器占用背包容量；玩家可通过增加容器容量收集更多元素，同时减少携带其他物资的空间。

| 存放位置 | 建议承载对象 | 希望形成的选择 |
|---|---|---|
| 法杖 | 当前编排、用于施法的法术，使用独立法杖容量 | 本次战斗和探索采用怎样的组合。 |
| 容器 | 收集或携带的元素材料 | 采集什么、保存多少、何时取用。 |
| 背包 | 容器、补给、掉落物与其他实体道具；同种物品有上限地堆叠，可丢弃 | 在材料携带、战斗准备与新收获之间分配空间。最多携带 3 根法杖，备用法杖具体占位待定。 |

法杖槽位、容器储量与背包空间分别计量。背包已经确定采用二维格子，按物品尺寸、形状和朝向拼放；容器内部材料储量采用什么单位，以及是否叠加重量限制仍待定。建议容器同时标明占用的背包格子与可储材料量，方便玩家比较携带取舍。备用法杖与未装入法杖的备用法术是否进入背包，需要后续确认；不能将该待定问题混同于已装入法杖的法术槽位。

玩家可能选择使用一份稀有材料提高本局生存率，也可能保存它，争取撤离后用于据点实验。容器涉及各种元素，因此后续设计要能表达固体、液体、气体的收集与保存；具体工具、容量单位、密封条件及收集速度待定。

### 3.3 法术与材料的资产规则必须相容

资产分类已经明确采用“多种冒险道具，多数可消耗；知识、某些被动技能与部分据点道具永久保留”的方向。仍需讨论：

1. 法术已分无限使用与有限次数；具体哪些属于哪类，有限次数如何扣减，法术组合与持有数量之间如何关联？无限次数仅说明次数不耗尽，Mana 或材料等施法开销仍待设计。
2. 法术生成的材料是否可以采集并带出？若可以，生成与采集有哪些资源条件？

如果某种稀有材料能够通过可无限恢复的 Mana 免费生成，再无限收进仓库，探索发现这种材料的价值就会下降，世界中的材料量也可能持续增长。

已经确定：法术具有自身元素，例如毒球自带毒、火球自带火。玩家可以选择将容器材料附着在法术上；容器材料是可选附着，法术能够独立释放，容器为空也能正常施法。容器材料当前有两种已确定用途：直接释放，以及选择附着在法术上。

附着配置属于某份已装入法杖的法术，同名法术可分别设置。配置持续保留，目标法术实际产生输出时取料，直到玩家关闭、调整或材料耗尽；材料耗尽时维持普通施法。附着对象与持续方式已得到认可，具体剂量、来源关联及组合输出计量后续再定。

建议附着消耗实际投入的容器储量，并让剂量可读。多重施法或分裂时，附着材料应按实际投放总量分配或扣减，避免同一份稀有附着材料被无成本复制。具体计量和配置尚未确认。

附着后的材料可以参与未来规则表定义的反应，具体效果未必总是增加伤害。附着时、飞行中或命中后何时发生反应仍待设计；当前不写固定元素组合效果，也不保证所有材料组合都只产生正向增强。

炼金具体内容由用户后续提供的规则表决定，当前仅保留扩展需求：材料能够按稳定身份被识别，容器内容能够表达各组分及数量，后续规则能够描述参与物质、条件与产物。具体表格字段、数值、反应组合与运行方式留待后续专题，本轮没有新增代码接口。

## 4. 两个模式与据点的关系

单机箱庭负责探索、战斗、搜集、撤离与长期物资积累。PvP 负责玩家之间的法术对抗，其具体目标尚待确定。

PvP 有两种需要后续比较的方向：

| 方向 | 玩家体验 | 主要取舍 |
|---|---|---|
| 竞技 PvP | 在统一资源或配置预算下组合自己的法术，胜负主要来自组合与操作。 | 需要决定哪些已拥有的法术能够使用，以及如何控制组合强度。 |
| 资产 PvP | 使用仓库物资参与对抗，可能争夺、消耗或失去资产。 | 单机资源积累、装备差距与对局损失需要一起设计。 |

此前提出先讨论竞技 PvP，保留玩家自由组合的特色，并为不同积累程度的玩家建立可比较的对抗条件。这只是尚未认可的历史建议；该专题现已延期，不进入当前开发范围。

### 4.1 已延期的候选：竞技 PvP 与单机资产的关系

以下 7 点均为候选方案，尚未得到用户认可。用户已明确暂停 PvP 讨论；保留这些内容仅供未来回顾，当前不确认、不实施，也不以联网或竞技需求约束单机开发。

| 编号 | 当前推荐方向 | 设计目的与取舍 |
|---|---|---|
| 1. 资产关系 | PvP 使用独立对局配置，不扣单机仓库中的法术次数和材料，也不因输掉对局遗失单机装备；对局发放材料不能带回仓库 | 鼓励反复试验和对战；单机收集价值主要来自冒险用途与资产积累，PvP 不直接押注这些资产。 |
| 2. 法术来源 | 双方使用同一公共对战法术库，玩家自行编排法杖；不要求先在单机拥有某份法术，公共库只包含适合当前竞技规则的法术与材料 | 让探索进度不同的玩家获得同等选择；单机稀有发现的独占优势不进入首个竞技模式，库的范围和版本更新需明确。 |
| 3. 配置与能力 | 统一角色基础属性、法杖槽位及容量、Mana 等施法资源规则和容器材料预算；强力组合可受公开配置预算约束，参与竞技的被动能力采用双方相同的公开可选池与有限装备名额，单机累计加成不直接叠加 | 保留组合策略与操作差异，避免累计成长直接成为数值优势；具体预算、哪些能力参与和数值待定，学习到的规律自然仍有用。 |
| 4. 对局结构 | 首个竞技模式建议 1v1、三局两胜；生命归零结束当前回合，每回合设有限时长，超时与同时死亡的裁定另行设计；回合间可在同等规则下调整配置 | 小范围对抗便于聚焦法术和元素玩法，也更容易控制对局规模；人数、胜场制和具体时长仍是候选，不代表联机已经实现。 |
| 5. 元素与场地 | 专用有限竞技场提供掩体、路线和少量共享材料，保留同一套法术编程与材料身份、互动规则；模式可以采用公开数值或资源限制，具体配方仍由未来规则表决定 | 元素用于争夺空间、创造路径和组合应对，继承单机学习；双方可能受影响的世界状态应遵循一致结果，不能各按自己视野停止真实游戏状态。 |
| 6. 回合生命周期 | 同一回合内材料持续存在并按世界规则变化，回合结束通过明确过场重置场景材料、生命与对局储量，比赛结束释放实例 | 回合不继承前一回合的场地优势，也避免跨回合和跨比赛累积；仍需约束单回合输出并优化模拟，重置不能独立保证帧率。 |
| 7. 奖励与长期目标 | 初期以胜负记录、组合试验和竞技成就为主；外观或展示性奖励是后续候选，暂不以大量稀有材料和装备作为默认对战奖励 | PvP 和单机都有独立游玩动机，避免默认将 PvP 变成更高效的单机稀有资源来源；排名、奖励频率与经济关系后续设计。 |

核心取舍是 PvP 的公共对战库与单机收集之间的联系：当前推荐将材料知识、编排经验与组合方案带进竞技，将库存和装备风险留给单机；若用户希望收集进度影响对战，可另行比较已拥有法术入场、租借缺失法术或独立资产模式。本轮不将这些备选方向混入首个竞技模式。

对局材料、有限法术次数等按回合规则真实消耗，下一回合按竞技配额重建，不改动单机消耗与保护规则。具体联网方式、权威判定、移动和材料同步属于之后的开发设计专题，当前没有启动实现。

当前处理：本组延期。重新启动 PvP 专题时再审议这些候选，当前单机计划不包含它们。

据点功能的候选职责：

- 模式入口：当前开发单机箱庭地图选择；PvP 入口延期。
- 仓库与准备区：存放带出物资，决定下一次携带配置。
- 炼金实验台：探索材料用途与转化规则，具体配方机制待定。
- 法术试验区：试验组合，确认材料与法术行为。
- 商城：用户已提出该功能，但 NPC 商店、游戏内交易或付费商城等具体含义待确认。

据点是否联机与 PvP 是否联机分别讨论；一个有模式入口和商店的据点地图，本身并不要求采用 MMO 世界架构。

## 5. 玩法结构如何帮助材料世界维持性能

本节记录后续设计原则与候选方案，尚未进行新的性能验证或实现。

### 5.1 一次冒险拥有一个有边界的世界生命周期

已确定把一次进入地图到撤离、死亡或主动放弃之间的过程作为独立冒险实例：冒险期间允许探索和返回，中途可保存继续；实例结束后，按结果结算允许带回的资产，旧实例的材料世界可以释放。再次进入同一张地图时建立新的冒险实例。具体规则见 2.3 和 2.4。

这一生命周期规则已确认。此前“离开区域后暂停，返回时恢复”的规则用于同一次冒险内的区域；真正结束冒险后重置世界，中途保存继续则恢复同一冒险的地面水池、冰块等改动。

### 5.2 收藏资源与实时模拟资源采用不同表示

建议让进入背包或仓库的材料保存为数量等材料数据，而不继续以世界中的 Cell、流体或气体运行。材料被取出并进入环境后，再恢复为参与世界规则的物质。

容器也建议采用这一方式：保存材料组分、数量与必要状态，容器内无需逐 Cell 模拟所有储存材料。具体保存字段、是否发生容器内反应与必要的更新成本后续设计，不预设所有库存材料都无条件停止一切变化。

采集实际转移材料已确认：收集多少，场景中的对应材料减少多少。直接释放与法术附着建议按实际投入量减少容器储量，具体计量待定。采集可以减少场上实时材料，但收集速度、库存容量和地图来源仍需受玩法规则约束。本轮仅确认玩法，没有实现采集机制或验证性能收益。

### 5.3 当前地图仍需管理材料的来源与去向

箱庭限制了地图范围，但同一场 Boss 战仍可能持续累积材料。实际成本还受活跃 Cell/Chunk、变化频率、表面更新、碰撞与透明层重叠影响，不能仅根据地图大小或材料总量保证帧率。

建议同时讨论以下机制：

- 采集：玩家把场上材料转入有限容器，减少场上实时材料；需要保留材料身份和数量关系。
- 消耗与转化：法术、炼金或敌人行为使用场上材料。形态转换本身未必减少成本，需要结合最终状态判断。
- 环境出口：排水、通风等玩家能够理解的路径，让材料移出当前活动场地。
- 自然变化：气体逐渐稀薄并消失、火焰消耗燃料；固体长期保留，外界条件触发转化的规则后续设计。
- 据点试验：每次试验结束后提供明确的回收或重置过程，避免据点跨多次冒险累积所有试验材料。

这些机制需要服从玩法和视觉直觉。地图内的隐藏物、敌人行为和持续材料源也要参与区域生命周期，玩家暂时看不见不能直接推导为所有因果都可以停止。

## 6. 接下来逐项确认的规则

### 6.1 当前专题：死亡损失与试验自由

已经确定：箱庭中死亡时，携带法术会丢失，无限使用的法术也适用；此前认可的出发前选择保护物构成需要细化的例外。无限使用不等于永久拥有。

某些知识、被动技能与据点道具获得后永久保留。已确定亲自观察验证的规律可以立即记录，需要带回的实体解锁物成功撤离后用于永久解锁；具体能力分类及炼金发现与验证机制仍需设计，见 2.4。

保护对象与初始额度已确定：第一版具有 2 个保护名额，每份法术占一个，不限稀有度；出发前选择，冒险途中不能更换保护对象，本局新搜获必须成功撤离才能保留。有限次数法术保留真实剩余次数，耗尽后消失；费用与成长扩展仍待细化。携带容器及材料、背包物品和法杖本体死亡时遗失已确认，未来是否扩展这些对象的保护尚未确定。

法术保护已确认按真实剩余次数结算，主动消耗不返还。第一版容器等其他携带物承担死亡遗失。基础配置具备可靠补给途径、保障重新出发的方向已确认，免费补齐基础配置的方式也已确定，套装规格仍待讨论。

玩家应能在出发前清楚看到哪些资产会丢失、哪些受到保护，以及保护的具体范围。

**已确认方向：出发前保护少量单份法术。** 以下记录比较过的方向，初始额度已确定，具体结算仍需继续确认：

| 候选方案 | 玩法作用 | 主要取舍 |
|---|---|---|
| 出发前绑定少量单份法术（已选择） | 玩家敢于携带珍贵法术，仍需撤离以保住本局搜获 | 保护边界容易理解，需决定数量或预算；容器、法杖本体等其他物品的保护可另行讨论。 |
| 冒险中可装入新物品的小型安全空间（未选择） | 发现少量珍贵物品时能先保证一部分收益 | 死亡也可能带回部分本局收获，需重新权衡撤离收益与安全空间容量。 |
| 保护整根法杖及其内部法术（未选择） | 容易保住玩家熟悉的完整施法组合 | 同一次保护可以覆盖多个珍贵法术，需要明确装载预算、途中替换与内容物保护范围。 |

用户已认可第一版以少量单份法术为保护对象，出发前选择并在本次冒险中锁定，冒险中新发现的法术不自动继承保护。同名的其他副本也不自动受保护，避免整类法术因保护一个副本而获得免损。初始额度为 2 份；费用与成长扩展仍待设计，容器、其他携带物和法杖本体的死亡遗失已确认。

保护结算已确认保留死亡时尚存的法术及其剩余次数，已主动消耗的次数不恢复；例如剩余 8 次出发、使用 3 次后死亡，保护后仍剩 5 次，数字仅用于说明。有限法术耗尽后消失，保护不恢复被主动用尽的法术；主动丢弃或销毁的处理后续再定。

**已确认方向：保护额度。** 初始使用固定 2 个保护名额，每份法术消耗一个名额，不按稀有度提高占用。玩家可以优先保护最珍惜的法术，同名多份分别计数，法术在法杖内仍使用原来的槽位；保护名额只记录受保护对象，不新增背包中的安全箱。

| 候选额度方式 | 决策方式 | 主要取舍 |
|---|---|---|
| 固定保护份数（已选择） | 从携带法术中选择有限份数 | 容易理解和调整；玩家可能优先保护最珍贵的法术，仍要在它们之间选择。 |
| 按稀有度或价值分配保护预算 | 保护一份珍贵法术，或保护多份普通法术 | 取舍更细，但需要提前确定稀有度、价值与额度关系，增加规则负担。 |
| 付费购买保护 | 根据愿意支付的资源选择保护对象 | 可以形成资产消耗，但玩家保护意愿受积累影响，需要一起设计经济和费用。 |

用户已认可固定 2 份法术作为初始规则和后续试玩的起点，可用于保护一份常用投放法术与一份重要修正法术，也可以保护两份其他法术；不限法术类别或稀有度。实际配置长度与失败后重建体验仍需试玩验证，不能声称这一数值已达到平衡。保护收费、成长解锁及额度上限本轮暂不确定。

保护额度与有限次数法术结算已确认，接下来讨论其他携带物的死亡损失。

**已确认：法杖本体、容器、背包与重新出发。** 本次携带的法杖本体、容器本体及其材料、背包本体与其他内容物均承担死亡遗失；仅按保护规则带回仍存在的受保护法术。本局新搜获继续遵循成功撤离才能保留的规则。据点仓库中未带入冒险的资产，以及已经取得的永久知识、能力和据点资产保持各自的保留规则。

受保护法术建议回到据点仓库，玩家可重新装入另一根法杖；保护某份法术不同时保护承载它的法杖本体。具体结算界面与收纳方式仍待设计。

为避免连续失败后无法重新出发，据点提供免费基础补给的方向已确认：在缺少基本装备时仍能取得基础法杖、小背包、普通采样容器与基本施法手段。具体资格判断、装备规格和基本法术种类待定；基础补给保障继续游玩，高级装备仍按各自获取规则积累。补给与材料采集收益之间的关系后续随经济设计检查。

讨论过的另一候选为保留已装备的法杖、背包及容器本体，只失去未受保护法术和材料、战利品等内容物。其失败后重建压力较低，但装备本体带出的价值与更换动力需要从容量、属性等其他设计中建立。第一版选择装备一起承担遗失，并通过基础补给保留重新出发的条件。

**已确认：基础补给方式。** 出发准备时可选择免费基础套装，确保玩家没有货币也能正常进入冒险；套装包括基础法杖、基本无限使用法术、小背包与一个普通采样容器，具体规格与基本法术种类待定。玩家可以按已确认的容量规则换装自己的物品；高级法杖、大背包、特殊容器与稀有法术继续通过探索或其他获取途径获得。

| 候选方式 | 失败后体验 | 主要取舍 |
|---|---|---|
| 免费基础套装（已选择） | 连续失败后无需先积攒货币即可再出发 | 需要限制套装囤积和直接变现，保留高级装备的获取价值。 |
| 低价购买基础物资 | 重新准备也有少量资源消耗 | 完全没有货币时仍需另一条可用的兜底途径。 |
| 临时借用基础装备 | 保证出发，回据点后归还 | 借用、损坏、遗失和替换会增加结算说明。 |

免费补给仅填补一套基础配置的缺项，已有对应补给物品时不重复领取；不设每日次数或等待时间，使连续失败不会阻断游玩。基础补给物品不可出售，也不可通过拆解直接兑换有价值资产；这些方向已确认。具体资格判断与仓库、装备、当前冒险间的关联后续设计，不声称现有规则已经消除了所有经济循环。

基础法术生成的材料仍按统一元素规则处理，不为其添加无法采集的特殊标签；免费材料的变现与炼金收益需结合后续经济和规则表设计。避免套装直接出售只能约束一种来源，不能独立保证材料经济平衡。

免费基础套装、只补缺项、不能直接变现及连续失败后仍可补领已得到认可，接下来讨论撤离规则。具体补给规格和后续成长仍待设计。

### 6.2 当前专题：资产分类与法术的消耗方式

用户已明确法术分为无限使用与有限次数两类，两类法术都属于携带物资，并承担箱庭死亡遗失规则。结合之前明确的永久资产，形成以下分类：

| 资产类别 | 当前确定的方向 | 仍待设计 |
|---|---|---|
| 无限使用法术 | 不受有限使用次数约束，箱庭死亡时也会遗失 | 对应法术种类、Mana 或材料开销、保护例外与配置规则。 |
| 有限次数法术 | 使用次数有限，保护或撤离保留真实剩余次数；耗尽消失，携带与死亡风险同样适用 | 多重输出的扣次数规则、特殊补充类型、耗尽后的法术程序行为与提示。 |
| 材料与其他消耗品 | 用于本次冒险，容器可收集地图中的元素 | 储量、使用方式、死亡损失与保护范围。 |
| 永久知识与能力 | 某些被动技能、炼金融合规律获得后永久保留 | 获取条件、同时生效规则、适用模式。 |
| 永久据点资产 | 部分道具获得后永久在新手村使用 | 具体用途与使用时是否消耗原料。 |

法术道具的持有数量、可使用次数和施法资源分别设计。一份可无限使用的法术仍可以需要 Mana，具体施法开销待定。容器提供可选材料附着，法术自带的基础元素保持独立施法能力。一次性法术可作为有限次数的一种特例，具体哪些法术如此尚未确定。

**已确认：法术保护与主动消耗的关系。** 保护保留死亡时尚存法术的真实剩余次数，已经主动使用的部分照常消耗。例如某法术出发时剩余 8 次，冒险中使用 3 次后死亡，受到保护时带回剩余 5 次；这些数字仅用于说明规则。该设计维持有限次数的消耗约束，避免通过死亡恢复使用次数。其他物品及储量的保护仍需另行设计。

**已确认：有限次数法术的结算与耗尽。** 在成功撤离或受保护后死亡时保留真实剩余次数，主动使用的次数不恢复。未受保护的法术死亡时遗失，继续遵循已确认的法术损失规则。

耗尽处理已确定采用消耗完即消失：最后一次正常生效后，该法术道具用尽，保护也不恢复被主动用尽的道具。法杖界面建议保留空位，不自动改变其他法术的排列；缺失指令造成的组合变化与提示方式需单独设计。冒险中的保护对象继续锁定，用尽后不把名额转移给新搜获。

讨论过的另一候选是保留耗尽载体，供后续充能或回收，其价值依赖新的补充、回收规则，也会占用携带空间；第一版未选择这一方向。特殊可充能类型后续另行设计，不默认所有有限法术均可补充。

剩余次数、耗尽消失与保护名额本局不能转移已得到认可。多重发射与触发输出具体如何扣次数、主动丢弃或销毁的处理继续留待后续设计。

基础配置通过免费套装补齐缺项的方式已确认，以防物资耗尽后缺少重新出发的条件。法术分为无限与有限次数，并不能独立保证场上材料总量受控；材料来源、消耗、回收与世界实例生命周期仍需要一起设计。

### 6.3 当前专题：法杖、容器与背包

用户已确认以下规则：

1. **容器既能收集，也能在箱庭中释放材料。** 收集的材料也能在顺利撤离后带回新手村实验。
2. **容器材料附着是可选操作。** 法术本身自带元素，容器材料为空时仍能正常施法；玩家可以选择直接撒出材料或让法术携带附加材料。
3. **采集实际减少场景材料。** 玩家收集多少，场景就减少多少对应材料。
4. **法杖容量独立，容器占背包容量。** 已装入法杖的法术放在法杖中；更多、更大容量的容器挤占其他背包物资空间。

这些规则使法杖负责组合与投放方式，容器承载世界材料，背包承担携带取舍；三者互相配合，同时保留法术独立释放的能力。

**附着对象与持续方式已认可。** 附着配置属于某份装入法杖的法术，同名法术可以分别配置；配置持续保留，实际执行产生输出时取料，直至关闭、调整或材料耗尽。材料耗尽后仍维持普通施法能力。

界面可以在对应槽位上编辑配置。移动法术时配置是否跟随、把法术取出法杖后如何保存等，后续再定。

一个候选配置示例，表中只表示载带材料，具体反应与效果由未来世界规则确定：

| 法杖中的法术 | 可选附着配置 |
|---|---|
| 第一份火球 | 从选定容器附着一份毒液 |
| 第二份火球 | 普通施法，无额外附着 |
| 水球 | 从另一个选定容器附着一份粘液 |

一次施法即使运行这些法术，也各自读取自己的附着配置。目标法术实际产生输出时取料；仅放在法杖里或本次未执行，不消耗附着材料。多重发射、分裂与触发输出如何分配材料还需细化，不能默认复制同一份稀有材料。

当前优先讨论实际产生投射物或材料载体的法术。若将附着扩展到改变后续法术的修正指令等，也需要明确其材料由哪些输出承载；本轮不限制最终范围，也不自动假设这些指令已有相同附着规则。

持续供料的具体操作仍待细化：如何选择来源和每次剂量、容器变化后怎样处理关联等。最新已确定不足一次剂量时部分附着；配置保留与实际消费分别设计，避免玩家无法判断某次施法是否投入了附着材料。

**额外容器用途：四个玩法方向已得到用户认可，具体效果、参数与实现仍待设计。**

| 已认可用途 | 玩法示例 | 后续需要细化 |
|---|---|---|
| 采集同时处理局部危险 | 吸取一部分地面毒液或毒雾，随着材料实际减少，局部危害减弱，获得材料和通行空间。 | 采集速度、范围、危险程度与容量限制。 |
| 少量投放试探环境 | 投放少量样本，观察特殊地形、机关或危险区域的响应，再决定是否投入更多。 | 随地图与未来规则表设计具体环境响应。 |
| 投掷易碎容器 | 把装有材料的易碎容器投向目标处，破碎后释放所装材料。 | 易碎容器的取得、投放与破碎规则，以及容器本体损失。 |
| 临时涂覆 | 把材料涂在装备或自身表面，产生与对应材料有关的接触或状态效果。 | 涂覆对象、持续状态与材料风险；效果由世界规则决定。 |

对四个方向的认可属于玩法范围确认，尚未形成开发任务或具体数值规则。

### 6.4 已确认方向：容器容量与样本分装

法杖容量独立、容器占用背包容量，以及扩大容器会挤占其他物资空间已确定。当前讨论如何存放多个材料样本，让容量成为有意义的携带选择。

以下是候选容器定位，尚未确认具体型号、占用空间、储量或数值：

| 候选定位 | 携带特点 | 使用目的与取舍 |
|---|---|---|
| 小型采样容器 | 占用较少背包空间，每个储量较少 | 分别保存珍贵材料；便于带回多种样本，但持续供料储量有限。 |
| 大型储料容器 | 占用更多背包空间，储量较大 | 清理较大材料区域或持续为法术供料，压缩其他物资的携带空间。 |
| 分仓容器 | 以内部独立储格分别保存材料 | 携带多种独立样本；建议隔离结构在同等外部尺寸下占用部分有效储量，使其与大罐各有用途。 |

以上用途可以与已认可的易碎投掷等外壳特性组合，当前不需要为每项功能指定一个固定型号。

**用户已认可：普通单腔允许多种材料同处，独立容器或分仓用于隔离样本。** 玩家既可以混装材料，也可以为保持独立样本付出额外存放空间。具体是否溶解、分层、发生反应等，留给用户后续规则表与材料行为设计；同腔存在多种材料不等于所有材料都会立即均匀融合或转化。

单腔混合物应保留实际组分，采集到混合区域时不默认得到纯净单一材料。建议供料源选择对应容器或独立储格，取用其实际内容；精细取样、分层取用与材料分离能力后续再定，避免仅凭点击名称就无成本分离混合物。此建议仍待确认。

容器选用可以形成不同出发目标：计划大量使用某种材料时携带大罐；计划研究多种未知材料时携带多个小瓶或分仓容器。外部占用已经确定采用背包二维格子，内部材料储量单位继续讨论。

建议界面清楚显示已用储量、剩余容量、材料组分以及独立储格，避免玩家在不知情时污染珍贵样本。密封、压强、材质差异与实际反应参数继续保留为后续设计内容。

该方向已确认。容器型号、储量、分仓容量代价与具体取料操作继续保留为后续细则，不将本轮确认扩展为所有候选数值或操作均已定稿。

### 6.5 已确认方向：二维格子背包

用户明确选择类似其描述的《三角洲》背包体验：在二维格子中按物品尺寸、形状与朝向拼放。物品摆放本身参与携带决策，剩余格子总数足够时，也可能因为空间不连续而放不下新物品。以下是本轮比较结果，具体实现与数值仍待设计：

| 候选方向 | 玩家如何管理 | 主要取舍 |
|---|---|---|
| 简单空间点数（未采用） | 不同物品占用不同数量的空间点，界面展示剩余容量，自动排布物品 | 携带取舍清晰、整理操作较少；物品摆放本身的玩法较弱。 |
| 二维格子与物品形状（已选择） | 根据尺寸、形状和朝向在背包中安排物品 | 摆放可以产生额外策略；探索途中需要花更多时间整理。 |
| 重量与负重 | 根据物品重量判断携带余量，可选择加入超重后果 | 容器装入材料会影响负重；需要解释不同材料重量，并可能引入移动与负重的额外规则。 |

建议优先用不同长宽的矩形占格表达物品，支持旋转朝向与拖动摆放。是否引入 L 形等不规则占格、快捷整理，以及是否叠加重量和移动惩罚，仍待讨论。具体背包长宽与物品占格数值不在本轮确定。

为让出发准备可预测，建议固定外形容器无论空满都占相同背包空间，内部材料按容器储量单独计量。采集增加容器内部储量，无需每次重新整理背包；倒空材料也不让容器外壳自动腾出空间，玩家可以放弃容器本体来换取其他战利品的携带空间。这是候选规则，尚待认可。

用户已确定同种物品可以有限堆叠且可丢弃，并认可普通消耗品、空容器、状态相同的法术堆叠；次数、附着或材料组分不同的物品分别保存，法杖独立。具体上限与装备位方式由配置及界面设计表达；堆叠后仍须保留每份法术的独立身份与保护关系。

背包方向已确认，固定外形容器空满占格相同等细则仍是建议，不能将本轮的二维背包选择视为同时认可所有候选规则。

### 6.6 已确认方向：材料如何进入背包

用户已认可让液体与气体存放在容器中，可搬运的稳定固体既能装入合适容器，也能以材料物品形式直接占用背包格子。需要隔离或特殊保存的固体可由未来材料规则要求适当容器，具体采集工具、可搬运尺寸与保存条件继续讨论。

允许稳定固体直接占格，可以使容器采样与固体搬运形成不同携带方式。该方向已确认；不预设玩家已能直接拾取整片地面或所有固体。

直接携带固体时，采集仍实际转移对应材料，物品记录其材料身份、数量与必要状态；建议库存内采用材料数据保存，不继续逐颗运行世界模拟。具体库存状态变化与重新释放方式后续设计，本轮没有开发采集或存储代码。

材料携带方向已确认，采集数量对应的固体占格、堆叠、容器空满占格相同等细则仍待讨论。接下来转入死亡保护范围。

已认可的边界细则：

2. 法杖有独立 Mana 上限、恢复速度、冷却、槽位容量与每次抽取数量；切换不重置，未握持时按自身规则恢复。
3. 修正/多重施法装在三根法杖内入场扣携带次数，背包备用卡本局首次安装补扣，卸下重装不重复；最后一次资格本局仍可用，终局后耗尽。普通产出按指令执行扣一次，分裂不倍增扣次；Trigger 与有限次数 Payload 成功施法开始预扣，未触发不退，Mana 不足整次失败不扣。
4. 状态相同的法术、空容器与普通消耗品有限堆叠；次数、附着或组分不同分别保存；法杖独立。堆叠不把多个保护对象合成一个身份。
5. 强退或主动关闭游戏按死亡结算；带入和搜获普通资产损失，尚存受保护法术保留，据点仓库保持。异常崩溃的例外和防重复提交留作技术方案，不宣称已确认完整异常恢复规则。
6. 首版有轻量条件基础撤离路线，Boss/深区可给更好收益或捷径，不要求每次少量取料完整通关。
7. 首版复用原场景结构，加入可采元素与元素机关，不全面元素化外部场景地板、墙体、家具。
8. 商店有限货源与收购预算，随明确冒险进展更新，反复进出不刷新；法术产生的材料维持统一身份。货币表达、具体刷新进展事件、稀有材料产出表及价格为后续实施配置。

此前头脑风暴中的非术法掉落、设备、永久被动与材料新增用途只保留为未来话题，不形成首版任务。不编造用户尚未提供的炼金配方。

### 6.9 首版单机完整功能说明

首版交付是一条可反复游玩的单机循环：据点整理真实资产、买卖与试验→选择携带物和保护法术→进入首张箱庭→探索、施法、采集与搜获→完成轻量撤离条件并返回→结算资产→继续整备与下一次出发。首版一张地图即可，不以剧情、被动或设备系统作为循环成立的前提。

| 功能组 | 首版应实现的玩家行为与规则 |
|---|---|
| 据点与仓库 | 保存跨局资产，存取法术、法杖、材料容器及背包物品；进行装配和出发准备，管理 2 个法术保护对象；失败后基础补给只补缺项。 |
| 三根法杖 | 最多携带 3 根，数字键切换，各自保存排列、Mana 与恢复、冷却、槽位及抽取数量；切换延续各自状态。 |
| 法术编程与次数 | 复用已有程序解释和组合语义；普通产出按执行扣次数，修正/多重施法按冒险携带资格消费，Trigger 预扣相关有限次数。支持两份同名法术独立次数、附着、保护身份。 |
| 二维背包 | 根据尺寸、形状、方向拼放物品，法杖程序槽容量单独计量；容器占背包空间；合法同类物品有限堆叠，能拆分、移动和丢弃，不因堆叠丢失身份与组分。 |
| 近距离采集 | 固定速度采集真实材料，世界减少实际转移量；混合区域采到实际混合组成。液体/气体用容器，合适的稳定固体可装入容器或作为材料物品携带。 |
| 容器三种使用 | 投掷后破碎，壳损失且释放真实存料；持续向前撒出；持续供料给某份法术。材料不足时部分附着，耗尽后基础施法继续；多产出分配不能复制材料。 |
| 首张箱庭 | 用户找一个场景；配置已有水、火、毒液、粘液、固体、气体等材料、敌人和探索收获。原场景结构先复用；有限资源与敌人本局消耗后不因远处返回刷新。 |
| 敌人及掉落 | 复用现有战斗与敌人系统；死亡按配置概率掉落法术，稀有法术获取更难、效果更强；首版不加入其他掉落物系统。具体敌人与掉落表依场景和试玩配置。 |
| 基础撤离路线 | 有轻量地图条件，如机关或钥匙守卫；解锁后到实际出口主动撤离，短倒计时期间区域内可移动/施法，受伤不取消，离开/主动取消重计，死亡失败。Boss 不挡住所有短途采样。 |
| 成功与失败结算 | 成功带回实际携带物与剩余次数；死亡/强退/主动关闭按失败，普通带入与新物资遗失，保留尚存受保护法术；耗尽法术不能通过保护复原。 |
| 首版商店 | 买卖法术、法杖、元素与容器；有有限供货及收购预算，随明确冒险进展更新；反复进出不刷新。免费基础套装不能直接卖钱/拆解变现，法术自产材料的经济按统一材料身份管理。 |
| 实验与法术试验 | 使用真实库存投放/组合现有元素、验证法术与已有世界反应；库存按实际转移扣除，保留采集/回收真实剩余材料的可能。不加入新的炼金配方、设备制造或特殊材料用途。 |
| 据点持久化与世界生命周期 | 据点资产持久化；箱庭不磁盘保存续玩。每次冒险重建初始实例，同局远处冻结、返回恢复，终局释放世界数据与表现，避免跨局累积。 |
| 性能与正确性验收 | 检查采集/释放数量、堆叠身份、扣次、保护、交易与结算；对同局连续施法、元素增多、远处往返和多次冒险分别验证 CPU/GPU/GC Alloc 及资源释放。玩法循环不作为无需性能验证的理由。 |

首版不实现：PvP/联网、剧情、多地图、永久被动、据点炼金设备、新炼金反应表、材料制作/设备供料等新增用途、更多敌人掉落类型、全场景元素化与破坏、箱庭保存续玩。临时涂覆不进入当前三种容器用法。

剩余内容按性质分开：

- 外部资产依赖：用户确定场景后，核对 URP 材质、比例、碰撞、路线与可放置内容，再确定敌人、材料与撤离机关位置。
- 可配置数值：背包/物品尺寸、堆叠上限、容器储量、采集速度数值、附着剂量、价格、掉落概率、Mana/冷却和撤离秒数；不会把旧计划初值当作用户已认可数值。
- 实施边界：费用不足/组合执行失败的原子性、保护与最后一次携带资格、异步场景切换和崩溃后的资产结算；技术方案明确后写入正式计划，必要分歧再集中询问。
