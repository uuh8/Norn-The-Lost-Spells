# 仓库分类网格与法杖选择卡配置指南

本轮为此前商店/仓库两阶段计划的第一阶段；购买清单和整单结算在第一阶段人工试玩确认后继续。仓库按具体 ContentId 汇总方格，背包保留真实形状。每份法术次数、容器内容和物品身份独立保存，界面上的数量来自真实实例。

## 1. 仓库法杖区如何精修

路径：`_UI/InventoryCanvas_仓库/InventoryWorkspaceRoot_仓库/MiddlePart/WandProgrammingRegion/BackpackRuntime_Wands`。

- `WarehouseWands_三个选择卡`：上排三个装备位。运行时每位显示实际法杖名称、Icon、Mana、就绪/剩余冷却，金色框表示正在查看的一根。点击只改变仓库展示，角色手持保持原选择。空位可以点击和拖入法杖。
- `SelectedWand_程序标题`：当前名称、法术槽已用/总容量、BaseDraws。
- `SelectedWand_属性`：当前/最大 Mana、冷却剩余/完整时长、Mana 恢复、预估根层蓝耗、受保护法术数量。保护数量表示程序内受保护法术实例，不是把法杖整个判为保护。
- `SelectedWand_程序滚动区/Viewport/ProgramContent_当前法杖槽`：仅当前法杖的程序槽。横向 ScrollRect 保留长程序，拖拽目标持有当前法杖 InstanceId；切换后不会把法术拖入上一根。Scrollbar 是横向滚动条，UGUI Slider 只是数值控件，二者职责不同。
- 同区域中的 `Spells` 是12格法术专区，继续保持独立额外容量。

调位置优先修改上面四个作者节点的 RectTransform Anchors/Offsets。Anchors 是父矩形中的比例位置，Offsets 是像素修正；上排卡片在运行时按区域宽度均分三份，不用逐张移动。仓库的 WandInventoryView 勾选 Selector Layout、Wide Layout，背包的 Selector Layout 保持关闭。背包仍使用三个 WandProgramPanelView 全部展开。

## 2. 分类格、拖拽与金币

两个窗口的仓库 Content 挂 WarehouseCatalogGridView。同种具体物品只显示一方格，例如南瓜与胡萝卜分开；总数不受背包 MaxStack 限制。重复点击已选中的同类方格切换具体一份，`N/M` 和法术次数/容器容量说明当前拖出哪一份。起拖后 Ghost 显示其完整 Shape，背包继续按真实位置、旋转、容量和临时红框重叠规则判断。

Cell Size 调仓库目录图标尺寸；Minimum Rows 是最低背景行数，真实 Content 行数随种类增长。视口只复用当前可见几行 View，仓库不会因为几百种物品生成几百行活跃 UI。不要在 Content 重新挂 GridLayoutGroup/ContentSizeFitter，它们会与池化定位竞争。

搜索/分类只筛显示，整理只对目录排序并回到顶端；这些操作不改变实例身份、归属、次数、成分、钱包或存档版本。商店的背包区域现在使用真实交互网格，可在携带背包和仓库之间拖动。右侧详情暂缓精修。

WalletView 的 Session 应指向 `_Systems` 中同一个 SinglePlayerInventorySession，Amount 指向金币数字 Text。显示值读取实际 Wallet，样板中的12,580不是初始发钱配置。稳定帧余额不变时不重复格式化字符串；购买/出售后同一会话所有可见金币栏同步。

DragGhost 是非资产预览。它不能接收 Raycast：Image/Text raycastTarget 关闭、CanvasGroup blocksRaycasts=false；结束/取消拖拽后隐藏。删除它会使拖动时失去占格预览和抓取点反馈。

## 3. Editor 应用和试玩

菜单 `Tools/Norn/仓库/应用选择卡与分类网格及金币（Undo，不保存）` 增量接线当前 SinglePlayer_Hub，保留外围作者布局，单组 Ctrl+Z 可撤销。该菜单不自动保存正式场景；查看后自行 Ctrl+S。

自动验证使用独立 `SinglePlayer_Hub_WarehouseShopReview.unity` 和内存 Profile，不代表正式资产数量。Review 创建时先设置 Active Scene 为副本，避免临时 GameObject 先生成在正式场景、再跨场景移动导致无关 Dirty 标记。

人工重点验证：进入仓库区域按 E；逐个点三根法杖，看下方只有一根、名称/属性/程序对应；把法术拖到第二/第三根后切回检查归属；空程序保留空槽；Tab 切背包后三根完整展开；仓库同类物品次数不同仍能选择具体一份；搜索后清空恢复全部；商店背包与仓库双向存取；真实购买/出售后金币同步；退出 UI 恢复时间和光标。
