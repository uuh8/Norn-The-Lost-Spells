# 施法节奏、寿命与地图性能修复

状态：本轮四项完成。相关EditMode 123/123，核心PlayMode按最新用例合并39/39；三图Native Profiler前/中/后采样、10份水材质参数/GUID保持、正式场景文件字节保持均有证据。额外4项继承的旧Review背包检查失败单列，未把它们称为通过或确认既有失败。最终记录见 `docs/superpowers/evidence/2026-10-19-spell-world-performance/README.md`。

用户授权处理四项现有问题，已确认短寿命改为每张将剩余寿命减半。使用原工作区、现有模块，不使用 SubAgent、不重建用户扩展的据点、不改存档身份。

1. **先保存与采样**：备份当前正式场景和本次触及源文件；使用 Native Profiler 对 Hub/P7/P8 不施法暖态采样，记录 CPU、Render、GC 与日志，区分等待与实际工作。保留前后同条件数据，不能只用平均 FPS 推测根因。
2. **短寿命**：SpellDefinition 增加默认1的寿命倍率，贯通冻结的 CastModifierState、SpellProgram、EmitCommand、SpellCommandBaker、ProjectileBase。现有加秒字段保留兼容，统一公式 `(基础寿命 + 加秒) × 倍率`，最后仅做安全钳制。短寿命从−1.6秒改为×0.5，内容维护工具与描述同步。测试显式寿命、Prefab默认寿命、同组后置修正、触发独立层、两/三张及取消/终止语义。
3. **快速施放**：先检查真实提交的Cast Delay、Reload、动画出手三项门槛；仅在证实规则未传到Runtime时修复接线。真实Owned施法已证实0.8−0.12=0.68秒正确提交，整轮结束时更长Reload会覆盖它；StarterA默认Reload随基础0.8秒兼容，因此只装一发时恰好没有总间隔收益。保留动画达到ArrowSpawnTime才发射，补充卡片说明。Reload仍由快速周转负责，不改变原正确机制。
4. **Beffio Water**：复用 `Art/Environment/BeffioURP/BeffioDecorativeWaterURP.shader`，通过 Editor 工具将资源包旧 Water/Water_Mobile 材质接到 URP 实现，保留颜色、Normal、UV、材质GUID和场景Transform。现有 Reflection_pass 已有SRP保护，检查实际是否创建额外Camera。无需用户新增资源；复用原 Normal PNG、颜色与已有Shader，不新增贴图或VFX。装饰水保留光照、法线滚动和透明度，原 Built-in GrabPass/平面反射不搬进URP。
5. **性能修复与回归**：只针对Profiler确认的瓶颈改动，不降低游戏规则或关闭玩法来换帧率。复测不施法、连续普通施法、触发和材料施法；P8也单独采样。验证实际伤害、动画释放、资源/库存、传送与回程。最后恢复正式Hub，保留作者布局。
