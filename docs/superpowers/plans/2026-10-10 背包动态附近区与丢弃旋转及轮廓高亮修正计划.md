## 1. 当前证据与全局约束

本轮先从玩家的操作路径检查：大物品能否看全；附近物品很多时能否找到目标；背包满时能否直接丢出；拖动和点击能否区分；物体高亮后是否仍保持自己的颜色。前一版只验证少量物品显示和材质资产不被写入，未充分验证这些体验，不能用先前测试通过来证明本轮问题不存在。

## 2. 玩家行为约定与方案取舍

### 2.1 附近区：铺满、扩展、滚动

维持当前大格子，不把大物品缩小以塞进两行。基础网格至少铺满可视区域，并保留一行空白；实际物品排布超过这个范围时增加 Content 行数，最宽物品超过可视列数时增加列数。横纵 Scrollbar 按溢出显示，鼠标滚轮滚动列表；拖拽物品到附近区边缘时也应能自动滚动。

形状依旧由同一 first-fit 排布，不按世界坐标摆放。接近新物品、拾取、丢弃、离开范围时刷新；Refresh 保留并 clamp 原来的滚动位置。玩家本次丢出的物品在刷新后滚入可视范围，以便确认它确实已到地面。

“无限生成固定格子”会浪费 UI 节点；“缩小全部格子塞满区域”会使图标难辨。采用有限可见区域加动态 Content，格子/物品视图池复用，集合变化才重新排布。

### 2.2 两种丢弃方式同时支持

- 拖到附近区域：空白背景、网格空格、已有附近物品上释放，均提交一次真实 Drop。释放点不是地面精确坐标，物品仍生成在玩家附近可拾取的位置。
- 拖到整个背包面板外：移动时提示“松开丢弃”；仅左键释放提交 Drop。以实际界面 RectTransform 为边界，不能使用全屏 Canvas 的 Rect 代替。
- 在面板内的无效位置释放：回到原位，不丢弃；按 Esc、关闭背包或窗口失焦：取消，不丢弃。
- 只有已经携带的实际物品执行 Drop；拖附近的地面物品到界面外保留地面物品，拖道具栏的快捷引用到界面外不丢真实资产。
- 普通拖拽遵循现有整叠语义；Shift 拖拽仅丢指定实例。成功的 OnDrop 已结束拖拽，后续 OnEndDrag 不得再次提交。

丢弃通过原有事务保证：成功后背包释放占格、场景存在真实代理、附近列表能看到同一 ItemId；失败时资产仍在原位，并给出失败原因。

### 2.3 点击旋转

第一次点击某物品只选中；之后每点击当前选中的同一背包物品，顺时针增加 90°，四次回到原方向。更换物品后的第一次点击重新进入选中步骤。

图标、OccupiedCells、外框和真实 QuarterTurns 同步变化。保持占格左上角锚点，提交原有 Place/WholeStack 事务；旋转后碰到其他物品或越界，保持原方向/位置并提示“空间不足，无法旋转”，不自动挤开邻物、不只转图片。相同格位的堆叠一起旋转，避免把一个格位的组悄悄拆开。

拖拽不能顺带触发点击旋转。UGUI 的拖拽阈值、eligibleForClick 和输入生命周期需要真实 EventSystem 测试；右键、附近地面视图和快捷栏引用不执行此规则。

### 2.4 轻微发光：仅屏幕轮廓

推荐独立轮廓外壳（Inverted Hull）加屏幕覆盖遮罩（Stencil）：首先记录模型当前在画面上占用的区域，再绘制稍扩大的壳，只允许壳落在模型覆盖区之外的像素显示。原模型、原贴图、原光照继续照常绘制；不向原材质增加 Emission，也不叠加整面白色。

基础解释：模型顶点位于 Object Space；通过相机变换到 Clip Space 后，可以把外扩量按屏幕像素换算。Normal 决定顶点向外的方向；只画外壳的背面，再排除原模型覆盖区，会得到画面中的边缘。颜色和宽度由现有 Profile 配置，起始宽度约 1–2 屏幕像素、淡金色低强度，不依赖 Bloom。

透明/镂空模型是重要风险：仅靠深度遮挡会在透明瓶中露出外壳；遮罩必须排除内部着色。草药存在 Alpha Clip 时，遮罩按其原纹理和 Cutoff 裁切，不能把透明叶片平面变成发光方块。低多边形硬边模型还需平滑的外扩方向，不能修改原网格法线从而改变原物体光照。

取舍：Fresnel 根据法线与视线夹角加亮，在曲面上接近边缘，但低多边形的一整面可能一起变亮，不能作为本次最终验收方案。Screen Space RenderTexture 的膨胀描边可以处理复杂轮廓，但需新增 Renderer Feature 和全屏 Pass，范围与成本更大。本批先采用独立遮罩/外壳，保留原来的事件接线；若现有草药或透明瓶的真实素材无法正确表现，停止该项接线并展示失败截图和调整方案，不交付整面发光作为替代。

Stencil 参考依据：[Unity ShaderLab Stencil](https://docs.unity3d.com/6000.0/Documentation/Manual/SL-Stencil.html)；坐标变换参考：[URP transformation methods](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/use-built-in-shader-methods-transformations.html)。URP 支持 Stencil，具体 bit 的可用性和本项目兼容性必须实测。
