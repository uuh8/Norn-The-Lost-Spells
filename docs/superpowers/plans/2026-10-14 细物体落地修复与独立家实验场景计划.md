# M6-T22 细物体落地修复与独立家实验场景 Implementation Plan

> 执行方式：使用 writing-plans、systematic-debugging、test-driven-development 与 executing-plans；直接在当前工作区实施，不使用 SubAgent，不提交，不自动保存/丢弃正式据点。用户已明确要求计划完成直接执行，不再请求计划确认。

**Goal:** 修复细物体支撑漏检，把据点旧实验平台迁到独立家的平地场景，以家门口 PortalGold 按 F 往返。

**Architecture:** GroundChecker 仍在 Game.Character，使用无分配 Physics 查询并由角色更新确定检测时序。HomeSceneTransfer/HomePortal 在 Game.Run，通过既有 Core 门交互和淡入淡出事件连接表现；使用同一 ProfileSaveRepository，和平转场不建立 PendingRaid、不使用死亡清算、不授予副本法术资格。新场景沿用保存的据点基础设施、现代背包与角色相机，但去掉城镇地图和商店仓库站点，平地承载现有 ElementWorld。

**Tech Stack:** Unity 6000.3.16f1、URP、CharacterController、Input System、EventBus、ScriptableObject、EditorSceneManager、Undo。

## 1. 体验、边界及取舍

角色踩在可碰撞细栏杆时应保持 Grounded，可正常起跳；离开支撑仍进入 Airborne，侧墙、Trigger、自身Collider不得成为地面。当前起始球贴地且独立Update时序未固定，先以真实胶囊和细柱复现；不能简单增加探地距离，否则会在半空提前落地。采用抬高球起点并补偿Cast长度，脚底从CharacterController的center/height计算；角色移动前后显式采样，独立组件兼容原调用。

家的需求是新的实验场景位置，不扩展炼金配方或建筑玩法。采用独立Scene而非Additive常驻：旧材料世界可靠释放，避免双写入口及GPU资源并存。场景离开后元素不持久化，已采回材料、携带物和独立SceneKey的落地Items保留；延续现有库存/地面记录机制。实验范围覆盖家的平地；据点世界施法/容器材料写入关闭，普通丢弃/物体投掷保持。商店、仓库、P7/P8不改变。
