# M6-T21 普通 Items 投掷、右键详情与背包显示

用户已授权写完计划直接执行。本轮五项一起完成再交付测试，不使用 SubAgent。当前单一据点非 Play 且 Dirty=false；正式 Scene 仅 Undo 修改，绝不代保存/丢弃。

## 1. 体验、理由与取舍

修正/多重指令不是投射物，其角标全部为空；保留未来入局资格逻辑，不改次数数据。法杖信息只显示 MaxMana、CastCooldown，Mana/恢复/预估显示整数，数值格式化只影响 UI，不改变随机属性与实际资源精度。颜色沿本轮已完成方案。

普通 Items（食物、草药、实体材料）可装备道具槽，通过原长按 G 显示跟随镜头的抛物线、松开 G 投掷模型。普通物品落地变为同一实例的可拾取物，不消失、复制或转换元素；容器保持破裂后释放组分。暂不添加炼金配方/自动消耗。投掷依靠已有唯一账本与隐藏代理预约事务：模型准备失败保留物品，成功发射释放包/快捷位，落地创建隐藏 Pickup 成功后才提交新位置。到达飞行寿命/场景结束依原在途终止规则移除，不免费返还。复用 ContainerThrown 的物理协议和现有 ThrownContainer location 值，避免更改存档编号和并行建立第二套物理权威；通过数据 UseKind=Throw 区分普通物体，不伪造 Composition。

背包 RightPart（包括旧详情相关子节点）删除，LeftPart 扩至约44%，MiddlePart 使用余下56%，只调整这两个父区域，不修改作者 Wand/Attributes/Icon 内部坐标。右键物品卡、装备法杖及道具图标打开独立详情 Prefab；框显示名称、占位说明、关闭按钮，具体属性内容留待后续。点击背景或 Esc 关闭框，左键拖拽、选中、旋转保持。仓库及附近物品使用同一框；仓库现有右区暂保留。旧右键清快捷位改为查看，卸装通过拖回背包完成。

商店图片刷新优先实例 Icon，其次配置 fallback，最后保留作者 Image 原 Sprite。图片缺元数据不能把作者图片清空。摘要只显示背包名和“已占 X/Y 格”，删除重复“当前背包/携带背包”；容量标题简化为“已占 X/Y 格”。

## 2. 架构与文件

- Run/Inventory/ItemDefinition.cs、IInventoryReadOnly.cs：Throw 能力及资格指令只读标记；目录 SO 指定普通物品能力。
- Run/Inventory/ItemOwnershipStore.cs、Run/Containers/ContainerUseService.cs：通用在途归属、普通物体落地/终止，维持唯一实例及原子失败。
- Run/Runtime/SinglePlayerInventorySession.cs：落地 Pickup 先准备后绑定、据点位置记录；游戏逻辑不引用 UI/Character。
- Character/Interaction/ContainerUseController.cs：G 从实际已选道具取 ItemId，普通物品不走撒液体，纯模型与既有 Rigidbody 代理共用。
- UI/Inventory/InventoryItemView.cs、EquippedWandDragView.cs、ToolbeltSlotView.cs、SinglePlayerInventoryController.cs：资格角标隐藏、右键意图、弹窗生命周期/取消优先级。
- 新 UI/Inventory/InventoryInfoPopup.cs、Prefabs/UI/InventorySlots/ItemInfoPopup.prefab；InventorySlotPrefabs SO 引用。
- UI/Inventory/WandInventoryView.cs、WarehouseWorkspaceView.cs：整数/最大值、作者背包 Sprite fallback 与简短摘要。
- 新 Editor/SinglePlayerInventoryRefinementSetup.cs：创建/绑定独立弹窗 Prefab，更新 Items Throw 能力；隔离 Review 改父布局与删除旧右区；导出共享练习工作区 Prefab，正式据点最终 Undo 应用。
- 对应 Run EditMode / RunPlayMode 回归及 living explainer/验收记录。

## 3. 美术资源依赖

使用现有 Assets/_Project/ScriptableObjects/SinglePlayer/Items 的 WorldModel/图标、现有九宫格边框和 Font。弹窗暗色底板由 UGUI Image 绘制，无新外部素材需求。普通物品必须有纯美术 Prefab（现有食物/草药已具备），禁用模型行为/Collider，以统一代理承载 Rigidbody；若缺失模型，拒绝发射并保留物品，不能退化成蓝球。UI边框沿现有 Sprite 的导入/Border 设置，不改图片源资源。

## 4. 验证

EditMode：普通物品装备不占包、发射后只一份在途、无代理回滚、落地唯一实例、重复碰撞/终止、容器原组分守恒。PlayMode：实际 G 预览及模型 Rigidbody、落地 F 拾取、资格角标为空/Emit 正常；最大值/整数字体；背包无 RightPart 且左区变大；背包/仓库/附近右键同框；关闭不串入拖拽/游戏输入；商店作者图片运行保留。实际截图核对、稳定交互 scoped GC Alloc 采样；不把整帧分配或人工体验当作通过。

## 5. 回退与交付

保留旧资产 GUID，新增脚本 meta 由 Unity 创建。没有真实炼金功能、没有新购买/死亡规则、没有清空存档。正式据点 Undo 修改最后统一由用户保存；P7/P8 共享工作区 Prefab 同步更新，禁止同时加载三张地图测试。失败检查代理创建、权威位置/工具绑定、EventBus与材料世界路由，避免只隐藏UI掩盖重复资产。
