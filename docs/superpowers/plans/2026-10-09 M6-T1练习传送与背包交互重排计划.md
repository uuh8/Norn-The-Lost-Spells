## 2. 可审阅布局与交互

Tab随身屏幕界面分三栏，仓库仍近距离E进入专用仓库模式。示意尺寸以1920×1080参考分辨率描述，CanvasScaler负责屏幕缩放：

```text
┌ 背包与法杖 ─────────────────────────────────────── 关闭 Esc ┐
│ 背包（真实二维网格） │ [法杖1] [法杖2] [法杖3] │ 所选物品详情 │
│ 尺寸/旋转/有限堆叠  │ 所选杖：Mana/恢复/冷却等 │ 图标/名称/属性│
│                    │ 可滚动法术序列           │ 仅相关操作   │
│ 附近物品（独立格区）│ 背包中的可用法术         │ 容器组分或   │
│ 近距离列表/选中拾取 │ 可用道具 [瓶][瓶]……      │ 法术附着等   │
└ 状态/必要操作提示 ──────────────────────────────────────────┘
```

左下只显示同一当前Scene、实际距离内、尚在地面的拥有身份的物品；不把所有WorldItem远程列出来。E按下优先处理近距离仓库/商店，然后最近可拾取物品；长按E采集原材料功能保留。有合法位置时自动放入背包，优先当前朝向再旋转；没有合法摆放位置时物品原地保留，自动打开Tab界面让玩家移动/旋转其他物品，拖地面物品进合法格才提交拾取。已有地面代理继续做最终Scene/距离/版本校验，避免UI绕过空间限制。满包不自动挤出、删物品或额外扩容。

三杖顶栏对应既有装备位；点击中栏显示该实例属性：当前/最大Mana、每秒恢复、施法冷却/剩余冷却、程序容量、每次抽取和序列。蓝耗取纯解释器实际求值结果说明为当前一次施法预算，不把整串ManaCost之和误当每次蓝耗，Trigger预扣/递归不改。背包可用法术保留，程序编辑依旧提交既有命令。

右栏仅显示选中项，空选择只给短提示。容器显示真实总量/容量/组分及必要使用说明，产出法术才显示附着来源/剂量，携带法术在据点才显示保护操作。出发、补给、放弃、存档重试与撤离状态从常驻详情移到独立上下文动作区，不能丢掉写盘失败恢复入口。清除I与B等旧正式入口及过时提示；Tab/E/Esc/1—3/WASD/Space/Shift/鼠标按既有习惯保留。材料热键不随场景变更。
