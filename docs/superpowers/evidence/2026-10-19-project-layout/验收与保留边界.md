# 项目结构整理：当前验收与保留边界

2026-10-19。当前状态以本记录、hub-identity-validation.json、hub-latest-playmode.json 和 hub-all-editmode-summary.json 为准。其他带 first-stage/layout 前缀或首轮数字的文件记录较早子阶段，不能覆盖本次退役与命名调整后的结果。

## 1. 完成的整理

- ScriptableObjects 按 Spell、Character、Combat、Enemies、Items、Input、World、ElementField、Materials、Rendering 十个领域归位；九个业务 Assembly 的依赖不变。
- SpellDefinition、法术物品、法杖参数与程序归入 Spell；所有法术物品统一放在 Items，移除按开发批次划分的 V2 根目录与 Items/Library 历史分组。
- 文件名采用下划线与 PascalCase：Spell_Emit_Fireball、Spell_Modify_DamageUp、Spell_Multicast_DoubleShot、Spell_Copy_Alpha、Item_Spell_Emit_Fireball、Wand_ResearchRapid 等。既有 ContentId 与 InstanceId 不随文件名改动。
- 当前流程为主菜单→据点→携带库存进入 Home/P7/P8→提交后返回据点。旧 P7 开场库/法杖、RunSpellSession、RunSessionCoordinator、Palette/Frame 编辑器、旧数值说明侧栏及无引用的重复规则退出使用。出口不再授予全集或强制串行进入 Boss。
- Boss checkpoint 采用真实库存。返回主菜单同样先保存；失败则保留场景，成功后释放跨场景上下文。操作说明和共享 HUD 保留。
- 首轮删除 15 个历史 Scene 与 1 个 ReviewWindow；本阶段删除 32 个旧代码/资产/测试夹具，包括 17 份 Runtime 源码。累计退役 48 项；原件与 .meta 有归档。

不是所有包含 P7、P8、Test 的内容都能删除。当前 P7/P8 地图、NPC/Boss 的 CastEvaluator 与只读 WandLoadout、Warrior/Archer 的控制器/状态/Animator/Prefab，以及流体与材料诊断保留。场景加载键保留原值。旧物品别名用于恢复已存在的财产，两个别名的规则与 Icon 仍共用原资产。

## 4. 本次排错中修正的遗漏

- 通用 basename 替换误碰普通实例键/模型名，及相对路径重复前缀：恢复稳定键，将资源路径、模型名和存档 ID 分别维护；统一路径的生成器复用实际 18 个模型定义做契约验证。
- 旧 Review 路径与动态 wand.* 拼接：正式玩家回归改读正式地图；测试首次写入内存 Profile，回程不抢正式上下文的恢复权。
- RequireComponent 依赖：先删除 Coordinator，再删除 Session。旧引导组件与 HUD 共用根节点，恢复后保留整套共享 HUD，只撤旧编辑器与 Session。
- 输入时序：UnityTest helper 先排队，下一帧处理松键，LateUpdate 再创建投掷物；测试等待这些真实阶段，不修改生产保护。
- 已撤销的 Hub 材料实验：正式 Hub 的 _allowWorldExperiments 原本为 false，实验组件也已撤下。旧“在据点投材料后进入副本”用例改为验证真实 G 请求被拒绝且财产完整；正向材料投掷由当前 P7/P8 真实输入路径验证。
