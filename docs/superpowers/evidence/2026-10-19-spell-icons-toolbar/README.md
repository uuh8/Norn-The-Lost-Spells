## 现象、根因与修复

十重不是复制十个火球，而是请求十次后续 Draw。用户七槽例子在足够 Mana 且从首槽开始时产出4颗根弹（触发火球、冰块、两颗普通火球）和1颗命中后粘液弹。100/120/500 Mana真实资源复现分别得到2/3/4颗根弹；费用不足的格子不产生 EmitCommand。

`draw-regression-red.xml` 保存修复前复现：实际请求11次而非10，两个不够Mana的火球被重复记为20次失败。当前失败请求在完整扫描无结果后结束，不再空转重读；第一次失败证据仍保留。玩家三重的同类配置由4次纠正为3次，双重为2次。Boss独立内容未调整平衡。

首次 PlayMode `icons-toolbar-playmode.xml/json` 为16通过/5失败。P7异常源于内容工具按终止弹旧名字重建重复定义，奖励和物品分裂；优先沿用既有物品引用、撤销副本后修复。另两项画布命中失败出现在该异常批次的黑屏/残留遮罩环境；修复P7根因后同一组完整重跑21项通过，没有改Raycast断言或降低点击要求。早期失败保留，不能把它和最终通过混为同一批结果。
