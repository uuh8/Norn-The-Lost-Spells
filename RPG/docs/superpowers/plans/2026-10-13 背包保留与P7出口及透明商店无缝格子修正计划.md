# 背包保留与 P7 出口及透明商店无缝格子修正计划

> 执行方式：用户明确要求写完直接执行，不另行确认；本轮自行实施，不使用 SubAgent，不 Commit，不自动保存/丢弃正式 Scene。

## 1. 玩家结果、原因和范围

本轮只修正已有规则和 UI 表现。死亡保留当前装备的背包本体、同一 InstanceId 和尺寸，背包内容、法术储存位、已装备法杖及道具仍遗失，金币与仓库仍保留；正式远征与 P7/P8 一致。背包保留是本体保护，不能递归保护背包内所有物品，也不能通过补发基础背包偷偷替换玩家购买的大背包。

P7 的真实最终出口目前先通过 PracticeSpellRewardAdapter.TryGrantLibrary 强制接收全集。储存位/背包满时，这条奖励路径发布 RequiresArrangement，背包因此打开，StageExitPortal 提前 return false。新版回程应先进入 HubPracticeSession.ReturnToHub，不以领取全集为前置；正常地图奖励仍保留，旧独立教学链的全集解锁也保留。验证必须填满法术储存位和背包，并在门边保留普通地面物品，实际按 F 测试，不只调用 TryEnter。

商店 Start 将面板 Image 的 alpha 写成 1，而背包/仓库使用透明全屏面板。修正商店根背景为透明，保留 Image 的 Raycast 和原分栏/详情占位，不移除输入遮罩、不改 Canvas 摄像机或作者材质。

网格当前通过 cellSize-1/-2 留出背景缝隙，物品实心格同样缩小。改成完整 cellSize 连续填充；细边线由独立 UGUI mesh 表达，不再以“漏出底板”表达格线。保留所有形状、坐标命中、抓取偏移、旋转、排序和虚拟化规则。不照抄参考图的搜索/未知物品玩法。

SpellStorageSlot 由 SpellStorageView 在 Refresh 离散扩池时创建；说明准确作者入口及 card Prefab。在现有 Spells 的组件 Inspector 开放槽背景 Sprite/Color，不新增模板系统或美术素材，用户随后自行精修。

## 2. 技术选择和资产

- 原样保留装备背包优于失败时寄仓或新建默认背包：回据点可马上使用原容量，位置父链保持合法。
- 门出口不补发全集优于无限扩容/自动寄仓：后两者偷偷改变奖励和容量规则，也掩盖不能退出的原因。
- 无缝底色 + 单个 GridLines Graphic 优于每格 Outline/四个 child Image：每区一个 mesh，线条颜色独立，虚拟仓库只画可见池，不随着无限行数无限扩 mesh。
- 复用现有字体、Icon、材质和 Portal Prefab，无需用户新增模型、Texture、音频、Shader。线条是 UGUI 几何，不是外部 bitmap。
- Game.Run owns 清算/出口；Game.UI owns 透明背景与只读网格。沿现有 EventBus/请求流，不添加反向 asmdef 依赖。
