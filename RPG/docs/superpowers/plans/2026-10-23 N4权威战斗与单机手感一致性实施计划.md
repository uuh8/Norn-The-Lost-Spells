## 约束与设计决定

- 默认 SinglePlayer 路径继续原样运行。在线 Authority、Replica 必须显式配置；Prediction 的战斗权限是 Replica，不能因本机负责移动预测而获得扣血权限。
- `Game.Combat` 不引用 Character / Skills / Mirror。执行模式和中性初始化契约放 Core；战斗固定步协调器放 Combat，Multiplayer 只负责组合与传输。
- 保留现有 Game.Multiplayer 对 Character / Combat 的实际依赖；通过 Character 的窄接口装配 Run 工作区，不从 Multiplayer 直接构造 SinglePlayerProfile，也不复制单机存档。
- 在线资源复用 V2 `WandExecutionTransactionService`。拒绝改走 Legacy 免费施法；不得让客户端发送伤害值或任意 Prefab 路径。
- 新 Run 满 Mana、零冷却、初始牌堆；同 Run 重连复用工作区，只更新 ConnectionEpoch。次数、无限资格与已安装卡的位置来自业务服冻结快照。
- `ContentManifestHash` 仍表示身份清单；另用玩法配置 Hash 保护 Spell/Wand/ActionTimeline 的规则，不能将旧身份 Hash 当玩法一致性证明。
- 固定 Tick 顺序：输入/动作 → 延迟创建与投射物运动 → 必要近战骨骼姿态 → SyncTransforms / Simulate → 范围与状态 → 导出事实。Frozen 不推进任何 Gameplay deadline。
- 新生对象明确 BirthTick；登记/注销不能破坏正在遍历的数组。稳态无 new / LINQ / Boxing；出生、网络可靠事件和 UI 离散刷新可有一次性分配，需分别量测。
- Client 的碰撞、AreaDamage.Start、Status.ApplyStatus、反射与资源 Spend 都有最终权限门；仅禁用攻击输入不足以建立权威。
- 不改第三方 Mirror；不改 Warrior / Archer 保留路径，不以静态前方盒替换既有近战骨骼命中。
- 每个阶段补中文注释、解释文档、实际证据；不得把编译通过写成可玩验收，也不得隐藏 N3 广泛回归 42 个失败与两条 native 启动错误。
