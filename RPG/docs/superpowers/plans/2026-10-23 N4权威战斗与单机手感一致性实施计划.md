# N4 权威战斗与单机手感一致性实施计划

> 执行方式：沿用已获用户授权的总计划连续执行，使用 subagent-driven-development / test-driven-development；Editor、测试、构建、Git 由主 Agent 串行管理。此文件包含设计与执行步骤，不另建 spec。

**目标**：2–4 人独立副本中，由 Dedicated Server 裁决 Owned 法杖、动作时序、投射物、伤害、状态、敌人与 Boss；Client 保持单机的输入、点击瞬间瞄准、移动施法与反馈。另修正用户报告的 Wizard 鞋底离地。

**依据**：2026-10-20 多人总计划 N4、已完成 N3、本轮明确的手感与接地要求。N5 材料网格、N6 持久结算、N7 宕机恢复、N8 公网性能仍独立验收。

**版本**：保持 Unity 6000.3.16f1、URP 17.3.0、Mirror 96.11.3、Protobuf 3.34.2 / protoc 34.2、ASP.NET Core 10.0.13、MySQL 8.4.13。此阶段无升级依赖的必要。

## 约束与设计决定

- 默认 SinglePlayer 路径继续原样运行。在线 Authority、Replica 必须显式配置；Prediction 的战斗权限是 Replica，不能因本机负责移动预测而获得扣血权限。
- `Game.Combat` 不引用 Character / Skills / Mirror。执行模式和中性初始化契约放 Core；战斗固定步协调器放 Combat，Multiplayer 只负责组合与传输。
- 保留现有 Game.Multiplayer 对 Character / Combat 的实际依赖；通过 Character 的窄接口装配 Run 工作区，不从 Multiplayer 直接构造 SinglePlayerProfile，也不复制单机存档。
- 在线资源复用 V2 `WandExecutionTransactionService`。拒绝改走 Legacy 免费施法；不得让客户端发送伤害值或任意 Prefab 路径。
- 新 Run 满 Mana、零冷却、初始牌堆；同 Run 重连复用工作区，只更新 ConnectionEpoch。次数、无限资格与已安装卡的位置来自业务服冻结快照。
- `ContentManifestHash` 仍表示身份清单；另用玩法配置 Hash 保护 Spell/Wand/ActionTimeline 的规则，不能将旧身份 Hash 当玩法一致性证明。
- 固定 Tick 顺序：输入/动作 → 延迟创建与投射物运动 → 必要近战骨骼姿态 → SyncTransforms / Simulate → 范围与状态 → 导出事实。Frozen 不推进任何 Gameplay deadline。
- 新生对象明确 BirthTick；登记/注销不能破坏正在遍历的数组。稳态无 new / LINQ / Boxing；出生、网络可靠事件和 UI 离散刷新可有一次性分配，需分别量测。
- Client 的碰撞、AreaDamage.Start、Status.ApplyStatus、反射与资源 Spend 都有最终权限门；仅禁用攻击输入不足以建立权威。
- 不改第三方 Mirror；不改 Warrior / Archer 保留路径，不以静态前方盒替换既有近战骨骼命中。
- 每个阶段补中文注释、解释文档、实际证据；不得把编译通过写成可玩验收，也不得隐藏 N3 广泛回归 42 个失败与两条 native 启动错误。

## 资源依赖

### 正式体验与技术验收的界线（2026-10-24 用户补充）

用户明确要求正式单机/联机完全复用现有 P7/P8 场景布置和 UI：Tab 背包、左上角道具栏、准心、状态 Icon、血条样式与角色操作反馈。网络只适配数据来源、命令与权威结果，不另建一套正式联机界面或背包实现。

当前 `MovementWorld`、`OnlineCombatHud` 是 N3/N4 的 Development 技术验收设施，不作为上线画面。本计划可以验收权威战斗、真实入口、重连和性能的本机技术基础；正式 P7/P8 内容与整套共享 UI 的接入必须另做完整体验验收，未完成前 `FormalOnlineExperienceAccepted=false`，生产 Rooms 继续默认关闭。不能把灰盒战斗通过写成正式副本体验已完成。

本阶段重用已有 WizardPlayer、SwordEnemy、远程敌人与 WizardBoss Prefab、对应 Animator/AnimationClip、Spell/Wand SO、投射物、命中 VFX、音效、正式字体及 UGUI。无需用户另找模型、纹理或音效；不引入新的外部包。Editor 从已有资源导出动作秒数与稳定 ContentId。缺失的攻击动画/Prefab 属配置失败，明确拒绝并报告，不能用错误的免费默认技能兜底。鞋底测量使用实际启用的 `MagicWand01/Shoe1` SkinnedMeshRenderer，不能拿骨骼或包围盒代替可见网格。
