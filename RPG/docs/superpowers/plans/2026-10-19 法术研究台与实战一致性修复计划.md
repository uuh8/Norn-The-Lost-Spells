# 法术研究台与实战一致性修复

用户要求继续直接完成，完成后检查相邻缺陷。本轮在原已批准系统上修复，不新增玩法规则或独立美术依赖，不派 SubAgent。

1. **库存呈现**：右侧只列尚未安装的可访问法术实例；安装、换位、换杖、拆卸后均重新读取权威库存。相同 ContentId 的其他实例保留，不能按图标去重。
2. **动画释放**：恢复 AttackDefinition.ArrowSpawnTime。V2 的地面/空中输入先锁定来源和瞄准，再经 PlayerWizardAttackState 到动画阈值才调用 ReleaseActiveCast。冷却和资源仍在实际提交时支付；按住继续射击，但不能反复重播起手吞掉当前发射。取消/暂停/换杖不得释放陈旧来源。原 Warrior/Archer 和 Legacy 不改规则。
3. **双触发弹**：先用真实 Hub→P7、实际库存实例和 InputSystem 复现五卡 [双重,触发,蒸汽,触发,冰]；逐层核对资源资格、Graph、Runtime Layer 和实发观察。根因经失败回归确认后修复；不能以重叠或视觉解释代替证据。
4. **实验区**：在 SinglePlayer_Home 添加独立 Box 区域、金色边界及 F 入口，复用同一研究 Controller/暂停/背包。不给副本开启权限，不恢复仓库或商店。单独 HubDefinition 只配置研究站点；V2 模式显式覆盖正式 Owned 场景和直接 Editor 练习入口。
5. **内容交付**：整理实际新增九卡的 ID、行为、SO/Icon 路径与图标建议；现有图标暂时复用。用户可提供 PNG 256×256 RGBA（透明背景），Texture Type Sprite、Single、sRGB、Alpha Is Transparency；不以图标未到阻塞规则修复。

修改集中在 Run 的库存只读投影/入口模式、Character 的输入及动画 State、Editor 接线工具、相关 PlayMode 测试。测试先补失败断言，再实现修正；复用当前 Editor 的官方 TestRunner，未保存场景/Play 不自动丢弃。

实证补充：初始三项回归 1/2，库重复与瞬发均复现；五卡 Hub→P7 正常。随后真实 Home 转场测试 0/2：Home 无研究入口；预览两根、实射一根，确认有限 Multicast 在和平试验未获资格而被跳过。统一策略：和平试验须持有且资格剩余>0（无限卡例外），不扣远征资格；Mana、普通弹次数、材料照扣；真正 Raid 仍必须在其资格集合中。仅 Run 权威入口能够给服务传入和平实验许可，UI 不授予。

本轮依用户第3项更正原 T6“动画仅反馈”的选择：每次法术在真实动画 ArrowSpawnTime 才提交。其代价是释放间隔包括起手时间和法杖冷却，不再宣称快杖可脱离动画达到旧测试中的0.05秒实射；快/重杖仍有不同冷却，不以加速或跳播原动画掩盖设计变化。
