> 使用 `superpowers:executing-plans` 在当前工作区逐项执行。用户本轮明确要求整理整个游戏目录并保持功能，已授权此重构；不派 SubAgent，不另建 worktree，不等待重复确认。

**Goal:** 去掉开发阶段充当正式目录的做法，以系统职责组织正式资源、Editor 工具和测试夹具；保留已有游戏结果和玩家数据。

**Architecture:** Runtime 的九个 Assembly 按领域划分已基本正确，保留它们的依赖方向。主要整理 ScriptableObject 归属、Editor 工具目录与 Assembly 名称；使用 Unity `AssetDatabase.MoveAsset` 保留资源及脚本 GUID，集中更新硬编码路径与生成工具，避免它们再次创建旧目录。

**Tech Stack:** Unity 6000.3.16f1、C#、AssetDatabase、SerializedObject、NUnit/Unity TestRunner。

**Spec:** 本轮用户请求及仓库 AGENTS.md，不另建 spec。

## 约束和设计理由

以内容职责判断归属，不以“本次开发/某一版”判断归属。同属法术的正式 SpellDefinition、程序、法杖数据、法术物品归到 `ScriptableObjects/Spell` 的对应子目录。输入配置归 Input，非施法物品归 Items，世界和关卡配置归 World，测试专用内容归 `Tests/Fixtures`。迁移前检查正式场景的依赖，不能把运行中的正式资源仅凭原名字像测试就误划为测试。

不修改 ContentId、InstanceId、存档 Schema、序列化字段名、Animator State 名、Resources 加载 Key。正式 Scene/Prefab 的作者布局保留；正式场景路径先保留，因为它们被传送门、RaidDefinition 和既有运行上下文当作稳定入口。阶段名保留在历史文档和兼容协议中，不再作为新正式资源根目录。

不引入新模型、贴图、VFX、声音、字体。上一项 Icon 合并继续完成；两个旧法术复用已有 Sprite，七个新机制的图标仍允许现有占位。

## 目标结构

```text
Assets/_Project/
  Scripts/                 # Core / Combat / Skills / Character / Run / ElementField / Materials / Rendering / UI
  ScriptableObjects/
    Spell/                 # Definitions / Items / Programs / Libraries / Wands / Compatibility
    Character/             # Wizard / Warrior / Archer 的角色配置
    Combat/                # 战斗通用数据与 Status
    Enemies/               # 敌人与 Boss 配置
    Items/                 # 非法术物品、容器、食物、药草
    Input/                 # 背包、法杖、交易 InputAction
    World/                 # Hub / Home / Dungeon / Practice 等世界配置
    ElementField/          # 材料世界模拟参数
    Materials/             # 材料类型与目录
    Rendering/             # 呈现参数
  Editor/                  # 同一 Game.Project.Editor Assembly 下按业务领域组织工具
  Tests/Fixtures/          # 自动测试、独立实验界面使用的 SO
```

## 必要修正：合并法术后的奖励规范映射

实际 P7 PlayMode 复现 `随机奖励法术未注册到Catalog`。根因是 ItemCatalogIndex.TryFindSpell 有意拒绝同一 SpellDefinition 对应两个物品 ID；合并规则、保留旧存档 ID 后必须显式解决反向查询，不能按字典遍历顺序随便挑一张。

- 在现有 Run 的 `Inventory/ItemCatalog.cs` 增加可选 `_canonicalSpellItems` Authoring 数组，冻结时验证其属于目录且每种法术只有一个规范物品；Index 先查明确映射，其余仍保持原唯一性规则。旧 ID 的正向读取和已有实例不变，不增加 Runtime Assembly 或存档 Schema。
- `Editor/Spells/SpellContentSetup` 给两种已合并规则指向旧完整法术库物品，保持奖励原语义；其他作者配置保留。
- 新增 `Tests/Run/SpellCatalogAliasTests.cs`，覆盖显式规范、未指定时拒绝歧义、非法映射拒绝、旧实例保存恢复；真实内容用例检查每个随机奖励均能反向解析。先 RED，再实现和执行内容接线。
- 这使最终 Runtime 源码差异从零变为 **ItemCatalog.cs 一份必要兼容修复**；不继续声称所有 Runtime 内容零变化。新字典只在目录冻结这一离散时刻分配，不改变 Update 热路径。
