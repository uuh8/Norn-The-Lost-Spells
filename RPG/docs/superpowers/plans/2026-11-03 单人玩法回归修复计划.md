本轮目标：恢复用户报告的四条原有玩家路径。保留统一账号资产和已经确认的单人 Dedicated Server 入口；修复不能依靠解除资产权威保护、导入旧档或在 Client 假扣资源。当前源码基线见《2026-10-31 Norn项目总计划（更新中）》§54、§61–64；不再按旧 AGENTS 的 N5 初期状态推断。无需新美术、字体、音效或第三方依赖。

## 1. 已确认事实与待定因项

1. 账号 Hub 的 `SinglePlayerInventoryController` 将所有 Presentation override 一律当作副本输入，跳过 `RunPauseCoordinator`，而 Hub 没有副本 Movement World 替它解锁鼠标。两个直接回归已于 2026-11-03T09:54:22Z 得到 1 passed / 2 failed；控制例为副本背包仍不能暂停共享世界。
2. 注册事务目前只有法杖与有限法术。基础包只由 `EnsureEntryBackpackAsync` 在入局时发放，所以新账号首次 Hub 明确可能无包。不能在 UI 虚构一个不属于服务器资产的格子容器。
3. 正式 Home/实验场的 `HomePortal` 仍要求旧本地 ReadOnly，随后 `HomeSceneTransfer` 还会保存旧 Repository；账号模式故意没有这个本地 Profile，因而入口失效。商店在交互、UI、Session 三层明确被账号分支拒绝；服务器交易适配确实未完成。
4. 副本拖放有现成客户端/DS 网关，尚未定位用户这一次失败的具体边界；正式 CombatInventory 的 `_status` 未接文本，拒绝原因会不可见。不能因缺少结果就解除版本/Owner/权限检查。
5. 用户补充确认：实际投射物、伤害、次数与 Mana 消耗均能发生和耗尽。第 4 项应调查 Prediction 动画与资源显示，而非修改扣费事务。
