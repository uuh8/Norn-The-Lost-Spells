# 仓库草稿与背包 Tab 配置指南

本次在你复制的 `InventoryCanvas_仓库` 上做布局草稿，保留现有金色边框与物品美术。仓库读取同一个真实库存，背包格子、法杖程序、法术专区仍使用现有视图；颜色用于帮助你定位和精修区域。搜索、分类、背包装备预览以及新的保护/附着排版当前是预留区域，后续确认交互后再制作。

## 1. 在 Hierarchy 中精修

展开 `__UI/InventoryCanvas_仓库/InventoryWorkspaceRoot_仓库`：

| 区域 | 节点 | 当前用途 |
| --- | --- | --- |
| 蓝色 | `LeftPart/WarehouseRegion_仓库存储` | 仓库图标目录，支持已有存入/取出命令；ScrollRect 随内容滚动 |
| 左上预留 | `LeftPart/WarehouseDraft_Search`、`WarehouseDraft_Filters` | 搜索和分类的布局文字，尚未接逻辑 |
| 绿色 | `MiddlePart/CarriedBackpackRegion_携带背包` | 实际装备背包的格子；保留 ScrollRect、Scrollbar、拖拽与中键平移 |
| 绿色预留 | `MiddlePart/BackpackEquipmentPreview_装备预览` | 后续放背包美术/装备说明 |
| 橙色 | `MiddlePart/WandProgrammingRegion` | 原三根法杖程序视图，沿用完整展示和法术拖拽 |
| 黄色 | 法杖区域原 `SpellStorageView` 所在节点 | 十二格随身法术专区，沿用既有额外容量规则 |
| 紫色 | `RightPart/ItemDetailsRegion_物品详情` | 既有基础详情；后续精修按类别的详细内容 |

选择区域的 `Image > Color` 调整标注颜色；`RectTransform` 改位置和大小。布局使用 normalized anchors：例如 `anchorMin=(0.285,0.03)` 是父矩形从左起 28.5%、从底起 3% 的点，`anchorMax` 定义另一角。`offsetMin/Max` 是对锚点的额外像素偏移。这样窗口缩放时三栏保持比例；小格子依靠滚动访问，不强行压缩到难以识别。

**Edit Mode 精修时，只启用内部 `InventoryWorkspaceRoot_仓库` 查看窗口。两个 Canvas 根节点保持启用。** 精修后可以关闭内部 Root；运行时控制器 Start 也会关闭它，进入仓库区域按 E 才打开。不要停用 `InventoryCanvas_背包` 根节点来隐藏背包。

## 2. 为什么之前 Tab 失效

保存场景中，背包 Canvas 根节点的 `m_IsActive=0`，它上面的 `SinglePlayerInventoryController` 不会运行 OnEnable，没有订阅 Tab 对应的 InputAction。仓库复制了控制器和同一套 Tab 引用，却没有 `_warehouseRoot`，因此既会接错 Tab，也不能消费仓库区域 E 的成功结果。

修正后，Canvas 根节点保持启用，显示隐藏由 `_panelRoot` 控制。只有背包配置 `_toggleAction`；仓库该字段为空。两者的 `_otherWorkspace` 互相引用，开一个会关闭另一个，暂停请求随之交接。仓库有真实 `_warehouseRoot` 和 `_warehouseTarget`，能接受区域 E 成功事件；区外/阶段限制仍由 Game.Run 复核。

复制出来的旧撤离 HUD 有些 Text 引用已经为空。本次只停用缺少文字引用的 `RaidResultView` / `ExtractionHud`，保留完整接线和整个撤离业务，不隐藏 Console 错误。

## 3. DragGhost 为什么保留

`DragGhost_拖拽物品预览（勿删）` 是拖动时跟随鼠标的临时物品图，显示图标、朝向、尺寸和抓取偏移。源物品仍属于原库存，松手后才由库存命令决定是否移动；失败或取消不会多出一份物品。

它在 Canvas 下单独存在，能避开背包的 RectMask2D 裁剪，拖到仓库、法杖或窗口外时仍看得见。`CanvasGroup.blocksRaycasts=false` 让事件穿过预览到达 DropTarget；如果预览挡住 Raycast，下面的格子收不到松手事件。平时 inactive，拖动才显示，两套窗口各需要自己的预览，不应删除。

## 4. 保存与试玩

作者入口：`Tools > Norn > 仓库 > 应用仓库颜色草稿与Tab修复（Undo，不保存）`。只处理正式 Hub 中两套命名的 Canvas；一组 Undo，Ctrl+Z 可撤销，不自动保存当前场景或改 Prefab/SO/玩家存档。

1. 检查草稿，Ctrl+S 保存场景修改。
2. 进入 Play，点击 Game 窗口取得焦点；Tab 打开/关闭背包。
3. 到仓库区域按 E，打开仓库；Tab 切回背包，Esc 关闭并恢复时间和镜头。
4. 背包物品拖入左侧仓库，再拖回绿色格子，不复制或丢失实例。
5. 搜索、分类和装备美术当前只是排版预留。

目录图标大小：仓库 Canvas 的 `SinglePlayerInventoryController > Warehouse Tile Size`（当前 112 reference units）。背包格子大小：`InventoryGridView > Cell Size`。仓库目录的一格不会改变物品在背包里的占格形状。
