# 普通物品投掷与右键详情框编辑指南

## 1. 玩家操作与数据

把食物/草药等 Items 拖到4–0道具栏后按对应数字键选择。按住 G 看跟随镜头的抛物线，松开 G 发射物品自己的模型；落地后仍可 F 拾取。背包、仓库与附近物品中的卡片可右键打开详情占位框，装备法杖与道具图标同样支持。框内目前只有物品名称和“详细信息待开发”，没有新增属性配置/炼金功能。关闭按钮、背景点击关闭；背包/仓库 Esc 优先关闭框，再按才关闭主界面。

Items 的 ItemDefinition Inspector 中 Use Kind 设置为 Throw，World Model 必须提供现有纯美术 Prefab。模型的 MonoBehaviour、Collider、Rigidbody 在投掷复制体中被禁用，统一 ThrownContainerProjectile 的物理根承载唯一 Rigidbody，避免两套物理互相拉扯。缺模型时不能发射，物品保留。现有能提供 WorldModel 的食物/草药/实体材料 SO 已增量设置能力；后续新物品需显式配置，Spell/Wand/Backpack不能冒充普通道具投掷。

## 2. 单独编辑弹窗

Prefab：`Assets/_Project/Prefabs/UI/InventorySlots/ItemInfoPopup.prefab`。

- Frame：窗口本体背景和整体尺寸。
- Frame/Border：现有边框 Sprite，可自行更换图片/颜色/九宫格 Border。
- Frame/Title：名称标题，只由代码更新文字和运行字体；位置、字号由 Prefab 负责。
- Frame/Body：详情内容占位，当前代码赋“详细信息待开发”；位置、字号可编辑。
- Frame/Close：关闭按钮，内部 Cross 是关闭符号。

`Assets/_Project/Resources/InventorySlotPrefabs.asset` 的 Info Popup 字段保存此 Prefab，和各 Slot 样式在同一配置里。不要直接编辑 Play 中的克隆体来修改永久样式。窗口外层是铺满当前面板的半透明背景，Frame按右键 Screen Space 坐标换算到父面板 Local Space 后夹紧，保证靠近屏幕边缘的物品也能看到完整窗口；只定位 Frame，不重排其子对象。

背包正式场景删除旧 RightPart，LeftPart扩大为约44%、MiddlePart占余下空间。父列的X范围被调整，Wand内部Attributes/Frame/WandIcon的局部位置保持作者设置。普通Slot的数量样式仍由原独立Prefab负责。

## 3. 为什么投掷不复制资产

装备已经把物品从 Backpack 移到 EquippedTool；投掷时先创建隐藏代理，成功后把同一 InstanceId 移到旧序列化编号 ThrownContainer 对应的在途位置，再 Launch。代理创建失败没有提交，快捷位仍保留。普通物体命中地面时先准备隐藏 WorldItemPickup，检查合法支撑，再修改唯一实例为 WorldItem、绑定并显示，原在途代理收到完成事件销毁。容器仍用原 Composition 投放材料，不走普通物体拾取分支。重复碰撞找不到活动 Flight，因此不会重复生成资产。

落地记录在据点沿用 RememberGround 和 HubWorldItemRecord，可随既有保存/返回机制恢复。飞行未结束仍阻止入口快照，寿命到期/场景卸载依旧清理在途资产，不免费返还。此轮只提供物体投掷，后续炼金需以真实落地实例作为输入，不能在UI里扣一份又在世界里生成另一份。

## 4. 显示规则

修正/多重指令不显示次数角标，Run 的本局资格/未来次数数据仍保留。Mana 和恢复取整只影响文字，真实随机 MaxMana/恢复精度不变；冷却只显示固定 CastCooldown，仍保留秒的小数精度。法杖标题与选择卡也只显示最大 Mana，实际 HUD 填充仍由资源状态推进。

商店背包图片依次使用实例图标、已配置 fallback、作者 Image 原 Sprite，避免未配置元数据时用 null 覆盖作者图片。摘要仅保留名称和已占格数；上方容量文字也简化。作者 Sprite 在 Awake 缓存一次，后续换包/重新打开仍有正确备用图片。
