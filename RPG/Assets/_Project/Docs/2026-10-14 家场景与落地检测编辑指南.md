# 家场景与落地检测编辑指南

## 1. 场景入口与作者对象

正式据点 SinglePlayer_Hub 的 __HubInteractions/HomeEntrance_家门 是逻辑入口；BoxCollider 仅为 Trigger，不自动触发。附近交互列表统一显示“F 进入家”。家的独立作者Scene是 Assets/_Project/Scenes/SinglePlayer/SinglePlayer_Home.unity，暂用 HomeGround_家实验平地 承载法术/容器实验。__HomeInteractions/HomeExit_返回据点 用 F 返回家门外。两处门都实例化用户的 Assets/_Project/Art/Prefabs/Portal/PortalGold.prefab，不改原Prefab。

门根Transform负责位置与触发范围。UnifiedPortalVisual 的原点是角色缩入的可见中心，PortalGold 是它的子对象；调整门宽/高应改视觉子对象，调整进入中心应移动 UnifiedPortalVisual。OutsideArrival 是回程落点；应放在入口之外的可站立位置，不能放在门的Trigger中，否则回程立刻再按F可能重新进门。门口逻辑根、视觉中心和落点分别配置，是为了让Collider不决定视觉中心。

## 2. 和平往返与实验许可

家不是P7/P8副本，不进行死亡遗失或随机奖励，不更换金币/仓库/装备。HomeSceneTransfer 使用原 ProfileSaveRepository，Save成功后才冻结写入、播放人物缩小/金门关闭/渐黑、Single加载新Scene，sceneLoaded早于Start，因此恢复原Profile后作者StartingInventory不会另发一套新档。返回时读取最后保存代，避免旧Scene的OnDestroy保存造成Generation倒退。

家中落地Items使用home.map1记录，城镇沿用原WorldSceneKey。两处地面物品记录同存于Profile，Scene实例只为自己的记录生成Pickup，因此回城不会把家里的地面物品摆在城镇，回家仍能重新拾取。元素模拟本身不保存；离开家释放ElementWorld及其GPU资源，已采回容器的真实材料仍留在库存。

SinglePlayerInventorySession 的 Allow World Experiments 是场景权限：据点关闭，家开启。它控制施法根资源准备和容器/材料写入，不靠UI是否显示来保证权限。普通Items丢弃/投掷仍属于物体位置迁移。家的 Allow Warehouse 关闭，避免没有仓库站点时通过Core命令远程改仓库。炼金配方/合成/台面是后续需求，本轮只提供区域与物理落地基础。

## 3. GroundChecker为什么改

CharacterController的center/height定义胶囊位置，Transform原点只是作者约定，不能始终当脚底。计算脚底时先把center转换到World Space，再减height的一半及缩放；检测球半径按胶囊半径适配，避免角色被细物体边缘支撑时小球覆盖不到。球起点增加skinWidth接触容差，Cast长度增加相同数值，保持向下探测距离不变，而非把空中位置过早当作地面。

Physics.SphereCast不可靠地报告与起始球已经重叠的Collider。SphereCastNonAlloc使用Awake前预分配的数组，过滤自身、Trigger及几乎水平的侧墙Normal；球扫边缘Normal再用命中Collider的短竖直Ray查询真实表面Normal，防止平栏杆被误当陡坡。滑坡仍沿用真实Normal和CharacterController.slopeLimit。

所有角色共享PlayerControllerBase.MoveCharacter：Move之后立即刷新GroundChecker，状态转换使用本帧位置；移动前再采样一次，避免依赖两个MonoBehaviour.Update的无保证顺序。Warrior/Archer及各攻击State仅替换共享移动入口，角色特有攻击/Animator/冲刺预算保留。GroundChecker独立使用时仍自行Update。

## 4. Editor与Debug

Home Scene已加入Build Settings，主菜单仍进入据点。修改家地形时给平地Collider保留Ground Layer；角色使用Input System和CharacterController，不替换为Rigidbody。实验世界的位置/数据域暂沿用原作者配置，后续扩大房间时须同步世界边界，不能只把地板变大。

若F不出现：检查HomePortal的Session/Player、BoxCollider.enabled/isTrigger和实际范围。若变黑后未加载：查Home日志、Scene路径和Build入口，不能新建存档掩盖恢复失败。若细物体仍掉入Airborne：检查物体真实Collider、LayerMask、脚底/检测球Gizmos和真实Surface Normal；没有Collider的纯模型不能成为支撑。零GC结论只针对Norn.Character.GroundProbe指定Profiler子树，不代表整个Editor帧零分配。

正式据点的删除和入口装配以Undo应用，不自动保存；用户保存后再统一体验。新增家场景可直接在Editor设计，重复prepare不会覆盖已有Home。
