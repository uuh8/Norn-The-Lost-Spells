旧 `norn.v2.double` / `norn.v2.damage` 物品 ID 继续有效，直接引用上述同一份 SpellDefinition；物品文件名带 Alias。审计确认无引用的重复 `spell.double/damage.asset` 已删除，Compatibility 目录已退出；同一个掉落候选池中的别名不会增加权重，商店原 OfferId/库存保留。当前玩家解释器仍按“同组最终修正”执行，能影响同组中位于它前面的弹；这是解释器规则，与更换增伤数值无关。

Catalog 显式指定这两种共享规则对应的规范奖励物品，因此 P7 的随机奖励仍有唯一的物品映射；旧存档中的别名实例仍能正向恢复。美术接入只需改原 SpellDefinition 的 Icon，并通过内容工具同步物品/商店；不需要为兼容 ID 单独准备图标。

**终止触发弹不是旧命中触发弹的重复卡。** 原 `Spell_Emit_TriggerFireball` 只在命中时触发，`Spell_Emit_TimedFireball` 按延迟触发；终止卡在命中或弹体自然寿命结束时触发，配合短寿命可在空中释放载荷。取消、离图不触发，因此保留独立卡与 Icon 需求。

三根新法杖：`norn.v2.wand.0` 迅捷研习杖（16 槽）；`norn.v2.wand.1` 重载研习杖（32 槽，固定快速周转）；`norn.v2.wand.2` 乱序研习杖（32 槽，Shuffle）。法杖图标可暂时沿用原资产；如要区分，建议分别使用轻型、厚重、旋转符文的轮廓。

## 1. 素材与导入

已接入（均在既有 `Art/UI/Skill_Icon/`）：法力回流 → `法力回流.png`；快速施放 → `快速释放.png`；快速周转 → `快速周转.png`；α/γ 借用 → `α借用.png` / `γ借用.png`；短寿命 → `减少投射物寿命.png`。文件名与显示名不必完全相同，以实际 Sprite 引用为准；保留用户原图与导入设置。

准备七张 `256×256 PNG RGBA`，透明背景，四周留少量安全边距；主体在约 48 像素显示时仍应能区分，不把细小公式写进图中。放进现有目录 `Assets/_Project/Art/UI/Skill_Icon/`，无需再新建版本目录。Unity 设置 `Texture Type = Sprite (2D and UI)`、`Sprite Mode = Single`、sRGB 开启、Alpha Is Transparency 开启；关闭 Mip Maps，Filter Mode 依整套现有图标风格采用 Bilinear，Max Size 256。UI 不需要 Normal Map、噪声纹理或额外 VFX。图标未就绪时继续使用现有占位 Sprite，不阻塞功能。

## 2. 接入位置与注意事项

每张新卡的 `Spell/Definitions/Spell_<资源后缀>.asset` 是 SpellDefinition，设置其 `Icon`；`Spell/Items/Item_Spell_<资源后缀>.asset` 是 ItemDefinition，设置其 `_icon`。二者应指向同一 Sprite：研究台冻结卡片使用 SpellDefinition，背包物品使用 ItemDefinition。商店 `World/Hub/Trading/Shop.asset` 的对应 Offer 也保存 Icon，需要一起同步。两张复用法术只修改既有规则的原图标。图标文件沿用已导入资产的 GUID，本次不重设用户新导入 PNG 的属性或图案。

终止弹定义已采用用户整理后的 `Spell_Emit_TerminationFireball.asset`，对应既有物品仍为 `Item_Spell_Emit_Termination.asset`。维护工具优先沿用物品所引用的定义，不会因规则资产改名重建旧副本。

`Editor/Spells/SpellContentSetup.Build` 是正式内容生成工具，保留既有法术 Icon 并同步物品及商店引用，不能在换好图标后覆盖回旧占位。资源应通过 Unity Inspector/AssetDatabase 修改，保留现有 `.meta` GUID。

## 3. 终止触发弹的图标方向

保持现有计时/接触触发弹的火球构图、暗色背景和像素风，只替换左上角辨识标记。推荐“正在熄灭、断开的光环，中心余烬散成三颗小光点”，表达父弹结束后释放内容；避免只画时钟（会与计时触发混淆）、撞击星芒（接触触发已使用）、骷髅或禁止符号（容易误读为死亡/取消）。48 像素小图仍应认得标记。

可给图像模型的提示词：以提供的火球 Icon 为参考，保留从左下到右上的橙黄色像素火球、深蓝黑背景与主体比例。左上角放一个清晰的大像素徽记：即将熄灭的断裂圆环，内有最后一颗亮余烬，向外散出三颗小光点，表达弹体结束后释放载荷。不要时钟、沙漏、撞击星芒、骷髅、文字、数字或额外边框。高对比、简洁轮廓，与参考图成套，缩小到48像素仍清晰。
